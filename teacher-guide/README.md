# ឯកសារសម្រាប់គ្រូបង្រៀន

> **សំខាន់៖ ថតនេះត្រូវផ្លាស់ទៅ repository ឯកជនដាច់ដោយឡែក។**

ថតនេះមានចំណុចណែនាំសម្រាប់ចម្លើយនៃសំណួររំលឹក។ ដោយសារ **សំណួរត្រួតពិនិត្យមានតម្លៃ ២០%** នៃពិន្ទុមុខវិជ្ជា ចម្លើយមិនគួរឲ្យនិស្សិតមើលឃើញទេ។

## ស្ថានភាពបច្ចុប្បន្ន

ថតនេះ **មិនត្រូវបានបោះផ្សាយលើគេហទំព័រទេ** ព្រោះវាស្ថិតនៅក្រៅថត `docs/`។

ប៉ុន្តែ repository នេះជា **public** ដូច្នេះនិស្សិតដែលចូលទៅ GitHub នៅតែអាចអានឯកសារទាំងនេះបាន។ ការលាក់ពី mkdocs មិនស្មើនឹងការលាក់ពីមនុស្សទេ។

## អ្វីដែលត្រូវធ្វើ

1. បង្កើត repository ថ្មីជា **Private** ឧទាហរណ៍ `gis-fundamentals-teacher`។
2. ផ្លាស់ថត `teacher-guide/` ទាំងមូលទៅទីនោះ។
3. លុបវាចេញពី repository សាធារណៈនេះ។

!!! warning
    ការលុបឯកសារចេញពី GitHub មិនលុបវាចេញពីប្រវត្តិ commit ទេ។ បើចម្លើយធ្លាប់ត្រូវបាន push ទៅ repository សាធារណៈ ចូរចាត់ទុកថាវាត្រូវបានលាតត្រដាងរួចហើយ ហើយសរសេរសំណួរប្រឡងថ្មី។

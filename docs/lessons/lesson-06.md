# មេរៀនទី៦៖ ប្រភព និងការប្រមូលទិន្នន័យ

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ៦ ក្នុងចំណោម ១៥

ការវិភាគ GIS ល្អប៉ុណ្ណា ក៏មិនអាចល្អជាងទិន្នន័យដែលវាប្រើដែរ។ មុនបើក QGIS អ្នកត្រូវសួរ៖ ទិន្នន័យនេះមកពីណា? ផលិតឆ្នាំណា? ត្រឹមត្រូវប៉ុណ្ណា? ខ្ញុំមានសិទ្ធិប្រើឬទេ?

មេរៀននេះណែនាំប្រភេទប្រភពទិន្នន័យ វិធីប្រមូលទិន្នន័យដោយខ្លួនឯង ជាពិសេសដោយ GNSS/GPS និងការរចនាទម្រង់ប្រមូលទិន្នន័យ។

---

## ៦.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. បែងចែកទិន្នន័យបឋម និងទិន្នន័យបន្ទាប់បន្សំ ព្រមទាំងគុណសម្បត្តិ និងគុណវិបត្តិ។
2. រាយប្រភពទិន្នន័យភូមិសាស្ត្រសំខាន់ៗសម្រាប់កម្ពុជា និងលក្ខខណ្ឌប្រើប្រាស់។
3. ពន្យល់ដំណើរការ GNSS កំហុសចៃដន្យ និងកំហុសលម្អៀង។
4. រចនាទម្រង់ប្រមូលទិន្នន័យដែលកាត់បន្ថយកំហុសបញ្ចូល។
5. វាយតម្លៃប្រភពទិន្នន័យដោយប្រើលក្ខណៈវិនិច្ឆ័យ៖ អ្នកផលិត ឆ្នាំ មាត្រដ្ឋាន ភាពត្រឹមត្រូវ អាជ្ញាបណ្ណ។

### ចំណេះដឹងមុនត្រូវមាន

- ខ្លឹមសារ[មេរៀនទី២](lesson-02.md) ដល់[មេរៀនទី៥](lesson-05.md)។
- គោលគំនិត CRS និងរយៈទទឹង រយៈបណ្ដោយ (សៀវភៅទី១៖ *ផែនទីវិទ្យា*)។

## ៦.២. ស្ថានភាពបើកមេរៀន៖ អណ្ដូងទឹកណាខ្លះនៅដំណើរការ?

អង្គការមួយត្រូវការផែនទីអណ្ដូងទឹកស្នប់ក្នុងឃុំបី។ ក្រុមការងារមានជម្រើសបី៖

1. ប្រើតារាងអណ្ដូងពីក្រសួង ដែលធ្វើបច្ចុប្បន្នភាពចុងក្រោយឆ្នាំ ២០១៥។
2. ប្រើចំណុចអណ្ដូងពី OpenStreetMap ដែលអ្នកស្ម័គ្រចិត្តបានបញ្ចូល។
3. ចុះទៅទីវាល វាស់ទីតាំងដោយទូរស័ព្ទ ហើយសួរអ្នកភូមិថាអណ្ដូងនីមួយៗនៅដំណើរការឬទេ។

ជម្រើសនីមួយៗមានតម្លៃ ពេលវេលា និងគុណភាពខុសគ្នា។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- តើប្រភពទិន្នន័យណាសមស្របសម្រាប់សំណួរនេះ?
- ពេលប្រមូលដោយខ្លួនឯង តើទីតាំងពីទូរស័ព្ទត្រឹមត្រូវប៉ុណ្ណា?
- តើរចនាទម្រង់ដូចម្ដេចឲ្យទិន្នន័យពីមនុស្ស ១០ នាក់ស៊ីគ្នា?

### ៦.៣.១. ទិន្នន័យបឋម និងបន្ទាប់បន្សំ

|---|---|---|
| និយមន័យ | អ្នកប្រមូលដោយខ្លួនឯង សម្រាប់គោលបំណងរបស់អ្នក | អ្នកផ្សេងប្រមូលរួច សម្រាប់គោលបំណងផ្សេង |
| ឧទាហរណ៍ | វាស់អណ្ដូងដោយ GPS · ស្ទង់មតិគ្រួសារ · ដ្រូន | ជំរឿន NIS · ផ្លូវ MPWT · OpenStreetMap · Sentinel-2 |
| គុណសម្បត្តិ | ត្រូវនឹងសំណួរ ដឹងពីវិធី ថ្មី | លឿន ថោក គ្របតំបន់ធំ |
| គុណវិបត្តិ | ថ្លៃ យូរ តំបន់តូច | អាចចាស់ និយមន័យខុស មិនដឹងកំហុស |

### ៦.៣.៣. GNSS និងកំហុសទីតាំង

**GNSS** (រួមមាន GPS BeiDou Galileo GLONASS) គណនាទីតាំងពីសញ្ញាផ្កាយរណបយ៉ាងតិច ៤។ ភាពត្រឹមត្រូវអាស្រ័យលើឧបករណ៍ និងបរិស្ថាន៖

| ឧបករណ៍ | ភាពត្រឹមត្រូវប្រហែល |
|---|---|
| ទូរស័ព្ទស្មាតហ្វូន | ៣ ទៅ ១០ ម |
| GPS ដៃ | ២ ទៅ ៥ ម |
| GNSS ពីរហ្វ្រេកង់ | ក្រោម ១ ម |
| RTK | ប៉ុន្មានសង់ទីម៉ែត្រ |

កំហុសមានពីរប្រភេទ៖

- **កំហុសចៃដន្យ (Random error)**៖ ការវាស់រាយប៉ាយជុំវិញទីតាំងពិត។ **ការវាស់ច្រើនដង ហើយយកមធ្យម** កាត់បន្ថយវាបាន។
- **កំហុសលម្អៀង (Bias)**៖ ការវាស់ទាំងអស់រំកិលទៅទិសតែមួយ ដូចជាសញ្ញាឆ្លុះពីអគារខ្ពស់ ឬដើមឈើក្រាស់ (multipath) ឬ CRS ខុស។ ការយកមធ្យម **មិនអាច** លុបវាបានទេ។

!!! example "ពិសោធន៍៖ ការវាស់ GPS"
    ប្ដូរឧបករណ៍ និងចំនួនការវាស់។ បន្ទាប់មក បើកជម្រើស «នៅជិតអគារខ្ពស់» ហើយពិនិត្យថាការវាស់ច្រើនដងជួយបានឬទេ។

### ៦.៣.៤. ការរចនាទម្រង់ប្រមូលទិន្នន័យ

នៅទីវាល មនុស្សច្រើននាក់បញ្ចូលទិន្នន័យក្នុងលក្ខខណ្ឌពិបាក។ ទម្រង់ល្អ **ការពារកំហុសមុនវាកើត**៖

| បញ្ហា | វិធីការពារក្នុងទម្រង់ |
|---|---|
| សរសេរ «អណ្ដូងស្នប់» «អណ្ដូង ស្នប់» «pump well» | បញ្ជីជម្រើស (Value Map) |
| ជម្រៅ ៥០០ ម ដោយវាយខុស | ដែនកំណត់តម្លៃ (Range) |
| ភ្លេចបញ្ចូលប្រភេទ | វាលចាំបាច់ (Not null) |
| កាលបរិច្ឆេទខុសទម្រង់ | តម្លៃលំនាំដើម `now()` |
| មិនដឹងអ្នកណាវាស់ | វាលអ្នកស្ទង់ |

កម្មវិធី **QField** និង **Mergin Maps** (ឥតគិតថ្លៃសម្រាប់ការប្រើតូច) បើកគម្រោង QGIS លើទូរស័ព្ទ ហើយប្រើទម្រង់ដែលរៀបចំក្នុង QGIS ដោយផ្ទាល់ ព្រមទាំងទីតាំងពី GNSS។

ក្រៅពី GNSS ទិន្នន័យអាចប្រមូលដោយ៖ ស្ទង់មតិ (សម្ភាសន៍) · ការគូសលើរូបភាពផ្កាយរណប (មេរៀនទី៧) · ដ្រូន · ឧបករណ៍ចាប់សញ្ញា (ស្ថានីយ៍ទឹកភ្លៀង) · ការផ្ដល់ពីសហគមន៍ (OSM)។

### ៦.៣.៥. វាយតម្លៃប្រភពទិន្នន័យ

មុនប្រើទិន្នន័យណាមួយ សួរសំណួរប្រាំនេះ៖

1. **អ្នកណា** ផលិត ហើយដើម្បីគោលបំណងអ្វី?
2. **ពេលណា**? ឆ្នាំនៃទិន្នន័យ មិនមែនឆ្នាំបោះពុម្ពទេ។
3. **របៀបណា**? វាស់ ស្ទង់ គូសពីរូបភាព ឬគំរូ? មាត្រដ្ឋាន ឬគុណភាពបង្ហាញប៉ុន្មាន?
4. **ត្រឹមត្រូវប៉ុណ្ណា**? មានរបាយការណ៍ភាពត្រឹមត្រូវ ឬមេតាទិន្នន័យឬទេ?
5. **សិទ្ធិ**? អាជ្ញាបណ្ណ និងការដកស្រង់។

ឧទាហរណ៍ ស្រទាប់ក្រប់ដីខេត្តកោះកុងក្នុងសំណុំទិន្នន័យវគ្គសិក្សា មកពីប្រភពបី៖ MRC (១៩៩៧) JICA (២០០៣) និងក្រសួងបរិស្ថាន (២០១៥)។ ពេលប្រៀបធៀបឆ្នាំទាំងបី យើងកំពុងប្រៀបធៀបវិធីសាស្ត្របីផងដែរ។ ចំណុចនេះនឹងសិក្សាលម្អិតក្នុង[មេរៀនទី៨](lesson-08.md)។

## ៦.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ តើការវាស់ទីតាំងសាលាដោយទូរស័ព្ទត្រឹមត្រូវគ្រប់គ្រាន់ឬទេ?

ក្រុមការងារត្រូវវាស់ទីតាំងសាលា ដើម្បីវិភាគចម្ងាយពីភូមិ (ដូច[លំហាត់ទី១០](../workbook/lab-10.md))។ ពួកគេមានតែទូរស័ព្ទ ដែលមានភាពត្រឹមត្រូវប្រហែល ±៨ ម។

### ជំហានទី១៖ កំណត់តម្រូវការភាពត្រឹមត្រូវ

ការវិភាគប្រើបាហ្វ័រ ៥ គម (៥ ០០០ ម)។ កំហុស ៨ ម ស្មើ ០,១៦% នៃចម្ងាយនោះ។ ភូមិដែលអាចប្ដូរថ្នាក់ «ជិត/ឆ្ងាយ» ដោយសារកំហុសនេះ គឺតែភូមិដែលនៅចម្ងាយ ៤ ៩៩២ ទៅ ៥ ០០៨ ម ប៉ុណ្ណោះ។

### ជំហានទី២៖ ពិចារណាកំហុសលម្អៀង

សាលាខ្លះនៅក្រោមដើមឈើធំ ឬជិតអគារបេតុង។ ទីនោះកំហុសអាចលម្អៀង ១០ ទៅ ២០ ម។ ការវាស់ ៥ ដង ហើយយកមធ្យម កាត់បន្ថយកំហុសចៃដន្យ តែមិនកាត់បន្ថយលម្អៀងទេ។ ដំណោះស្រាយ៖ វាស់នៅទីធ្លាចំហរជិតច្រកចូល។

### ជំហានទី៣៖ ប្រៀបធៀបជាមួយកំហុសផ្សេង

ចំណុចភូមិក្នុងជំរឿនតំណាងភូមិទាំងមូល ដែលមានទំហំជាច្រើនរយម៉ែត្រ។ ចម្ងាយបន្ទាត់ត្រង់ក៏ខុសពីចម្ងាយធ្វើដំណើរពិតជាច្រើនរយម៉ែត្រដែរ។ កំហុស GPS ៨ ម តូចជាងកំហុសទាំងនេះច្រើន។

### សេចក្ដីសន្និដ្ឋានដែលសមស្រប

> «ទូរស័ព្ទមានភាពត្រឹមត្រូវគ្រប់គ្រាន់សម្រាប់វាស់ទីតាំងសាលា ក្នុងការវិភាគចម្ងាយ ៥ គម ប្រសិនបើវាស់នៅកន្លែងចំហរ។ កំហុសធំជាងគេក្នុងការវិភាគនេះ មកពីការប្រើចំណុចភូមិ និងចម្ងាយបន្ទាត់ត្រង់ មិនមែនពី GPS ទេ។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"
    យើងមិនអាចសន្និដ្ឋានថាទូរស័ព្ទគ្រប់គ្រាន់សម្រាប់គ្រប់ការងារទេ។ សម្រាប់វាស់ព្រំក្បាលដី ឬកម្ពស់សម្រាប់គំរូទឹកជំនន់ កំហុស ៨ ម ធំពេក ហើយត្រូវប្រើ GNSS ពីរហ្វ្រេកង់ ឬ RTK។

## ៦.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «ទិន្នន័យពីរដ្ឋាភិបាល តែងត្រឹមត្រូវ»**
ទិន្នន័យផ្លូវការក៏អាចចាស់ ឬមានកំហុសដែរ (មើល[មេរៀនទី៨](lesson-08.md))។ វាយតម្លៃគ្រប់ប្រភព។

**២. «OpenStreetMap មិនអាចទុកចិត្តបាន»**
OSM នៅទីក្រុងធំៗច្រើនតែលម្អិតជាងទិន្នន័យផ្លូវការ ប៉ុន្តែនៅតំបន់ជនបទអាចខ្វះ។ គុណភាពប្រែប្រួលតាមតំបន់ ត្រូវពិនិត្យជាក់ស្ដែង។

**៣. «វាស់ GPS ច្រើនដង គឺលុបកំហុសទាំងអស់»**
ការយកមធ្យមកាត់បន្ថយតែកំហុសចៃដន្យ។ កំហុសលម្អៀងពី multipath ឬ CRS ខុស នៅដដែល។

**៤. «ទូរស័ព្ទបង្ហាញ ±៣ ម ដូច្នេះត្រឹមត្រូវ ៣ ម»**
តម្លៃនោះជាការប៉ាន់ស្មានរបស់ឧបករណ៍ក្នុងលក្ខខណ្ឌល្អ ជាធម្មតាប្រហែល ៦៨% នៃការវាស់។ ក្រោមដើមឈើ ឬជិតអគារ កំហុសពិតអាចធំជាងច្រើន។

**៥. «ទាញយកបាន គឺប្រើ និងចែកចាយបាន»**
ត្រូវអានអាជ្ញាបណ្ណ។ ទិន្នន័យខ្លះប្រើបានតែការសិក្សា ខ្លះតម្រូវការដកស្រង់ ខ្លះហាមចែកចាយបន្ត។

## ៦.៧. សេចក្ដីសង្ខេបមេរៀន

ទិន្នន័យបឋមត្រូវនឹងសំណួរ ប៉ុន្តែថ្លៃ។ ទិន្នន័យបន្ទាប់បន្សំលឿន ប៉ុន្តែអាចចាស់ ឬមានគោលបំណងផ្សេង។ ការងារល្អច្រើនតែបញ្ចូលទាំងពីរ។

GNSS មានកំហុសចៃដន្យ ដែលកាត់បន្ថយបានដោយការវាស់ច្រើនដង និងកំហុសលម្អៀង ដែលមិនអាចកាត់បន្ថយបែបនោះ។ ទម្រង់ប្រមូលទិន្នន័យល្អការពារកំហុសបញ្ចូល។ គ្រប់ប្រភពត្រូវវាយតម្លៃ៖ អ្នកណា ពេលណា របៀបណា ត្រឹមត្រូវប៉ុណ្ណា និងសិទ្ធិ។

!!! abstract "គំនិតស្នូលនៃមេរៀន"
    មុនសួរថា «តើទិន្នន័យនេះនិយាយអ្វី?» ត្រូវសួរថា «តើទិន្នន័យនេះមកពីណា?» ចម្លើយទីពីរ កំណត់ថាចម្លើយទីមួយអាចទុកចិត្តបានប៉ុណ្ណា។

## ៦.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. បែងចែកទិន្នន័យបឋម និងបន្ទាប់បន្សំ ដោយលើកឧទាហរណ៍ពីកម្ពុជាពីរសម្រាប់នីមួយៗ។
2. ហេតុអ្វីការវាស់ច្រើនដងមិនអាចលុបកំហុស multipath បាន?
3. រាយសំណួរប្រាំសម្រាប់វាយតម្លៃប្រភពទិន្នន័យ។
4. ហេតុអ្វីទម្រង់ដែលមាន Value Map ប្រសើរជាងវាលអក្សរសេរី?
5. ហេតុអ្វីការប្រៀបធៀបក្រប់ដីកោះកុងឆ្នាំ ១៩៩៧ និង ២០១៥ ត្រូវប្រុងប្រយ័ត្ន?

### ខ. សំណួរអនុវត្តគោលគំនិត

6. សម្រាប់ស្ថានភាពអណ្ដូងទឹកក្នុងឃុំបី សូមជ្រើសប្រភព ឬការបញ្ចូលគ្នានៃប្រភព ហើយពន្យល់ហេតុផល។
7. រចនាទម្រង់ប្រមូលទិន្នន័យផ្សារ (ទីផ្សារ) ដែលមាន ៦ វាល ព្រមទាំងប្រភេទ Widget និង Constraint។
8. សាលាមួយវាស់បាន ៥ ដង៖ ទីតាំងទាំងអស់នៅខាងកើតសាលាពិត ១៥ ម។ ជាកំហុសប្រភេទអ្វី? តើមូលហេតុអាចជាអ្វី?
9. ការងារមួយត្រូវវាស់ព្រំក្បាលដីទំហំ ២០ × ៣០ ម។ ទូរស័ព្ទ ±៥ ម គ្រប់គ្រាន់ឬទេ? គណនាកំហុសផ្ទៃដែលអាចកើត។
10. អ្នកទាញយកផ្លូវពី OpenStreetMap ដើម្បីបោះពុម្ពក្នុងរបាយការណ៍។ តើត្រូវសរសេរអ្វីខ្លះក្រោមផែនទី?

### គ. កិច្ចការខ្លី

ជ្រើសសំណួរ GIS តូចមួយក្នុងសហគមន៍របស់អ្នក។ សរសេរផែនការប្រមូលទិន្នន័យ ១ ទំព័រ៖ ទិន្នន័យដែលត្រូវការ · ប្រភពបន្ទាប់បន្សំដែលមាន និងការវាយតម្លៃ · ទិន្នន័យបឋមដែលត្រូវប្រមូល · ឧបករណ៍ និងភាពត្រឹមត្រូវដែលត្រូវការ · ទម្រង់ (វាល ៥ ទៅ ៨) · បញ្ហាសីលធម៌ (ការយល់ព្រម ឯកជនភាព)។

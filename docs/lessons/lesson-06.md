## ៦.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. សរសេរកន្សោមជ្រើសរើសតាមគុណលក្ខណៈ។
2. អនុវត្តសំណួរតាមលំហដោយប្រើទំនាក់ទំនងធរណីមាត្រ។
3. បញ្ចូលគ្នានូវលក្ខខណ្ឌដោយប្រើតក្កវិទ្យា Boolean។
4. នាំចេញ និងបកស្រាយលទ្ធផលជ្រើសរើស។

### ៦.៣.១. សំណួរតាមគុណលក្ខណៈ

### ៦.៣.២. តក្កវិទ្យា Boolean

*គ្រោង៖* AND, OR, NOT · ដ្យាក្រាម Venn · លំដាប់អាទិភាព

### ៦.៣.៣. សំណួរតាមលំហ

*គ្រោង៖* intersects · contains · within · touches · ក្នុងចម្ងាយ

*គ្រោង៖* ស្រទាប់គោលដៅ ទល់នឹង ស្រទាប់ប្រៀបធៀប

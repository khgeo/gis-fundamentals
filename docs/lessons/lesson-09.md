# មេរៀនទី៩៖ សំណួរតាមគុណលក្ខណៈ និងតាមលំហ

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ៩ ក្នុងចំណោម ១៥

[:material-presentation-play: ស្លាយបង្រៀនមេរៀននេះ](../slides/lesson-09.html){ .md-button target="_blank" }

មេរៀនមុនៗបានរៀបចំទិន្នន័យ។ ចាប់ពីមេរៀននេះ យើងចាប់ផ្ដើម **វិភាគ**។ ការវិភាគសាមញ្ញបំផុត និងប្រើញឹកញាប់បំផុតក្នុង GIS គឺ **ការសួរសំណួរ (Query)**៖ ជ្រើសវត្ថុដែលបំពេញលក្ខខណ្ឌ។

លក្ខខណ្ឌអាចជាគុណលក្ខណៈ («ភូមិដែលមានប្រជាជនលើស ៣ ០០០») ឬជាទំនាក់ទំនងលំហ («សាលាដែលនៅក្នុងតំបន់លិចទឹក»)។ មេរៀននេះបង្រៀនទាំងពីរ និងរបៀបផ្សំពួកវា។

## ៩.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. សរសេរសំណួរតាមគុណលក្ខណៈដោយប្រើប្រមាណវិធីប្រៀបធៀប តក្កវិជ្ជា LIKE និង IN។
2. ពន្យល់ទំនាក់ទំនងលំហ intersects within contains touches disjoint overlaps និង distance។
3. ជ្រើសទំនាក់ទំនងលំហត្រឹមត្រូវសម្រាប់សំណួរមួយ។
4. ផ្សំសំណួរតាមគុណលក្ខណៈ និងលំហ ដោយប្រើការជ្រើសថ្មី បន្ថែម ដក និងក្នុងការជ្រើសបច្ចុប្បន្ន។
5. ពន្យល់ថាហេតុអ្វីលទ្ធផលពីគុណលក្ខណៈ និងពីទីតាំង អាចខុសគ្នា។

## ៩.២. ស្ថានភាពបើកមេរៀន៖ សាលាណាខ្លះត្រូវរៀបចំផែនការជម្លៀស?

ក្រោយទឹកជំនន់ឆ្នាំ ២០១១ មន្ទីរអប់រំខេត្តកំពង់ឆ្នាំងចង់រៀបចំផែនការសម្រាប់រដូវវស្សាខាងមុខ។ គេត្រូវការបញ្ជីបី៖

1. សាលាបឋមសិក្សាដែលស្ថិតក្នុងតំបន់លិចទឹកឆ្នាំ ២០១១។
2. ក្នុងចំណោមនោះ សាលាដែលនៅក្នុងចម្ងាយ ១ គម ពីផ្លូវជាតិ ដែលអាចជម្លៀសបានលឿន។
3. ឃុំដែលជាប់ព្រំសង្កាត់ខ្សាម ដែលអាចទទួលសិស្សបណ្ដោះអាសន្ន។

គ្មានវាលណាក្នុងតារាងសាលាដែលមានឈ្មោះ «លិចទឹក» ទេ។ ចម្លើយត្រូវមកពីទីតាំង។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- តើសំណួរណាឆ្លើយបានដោយតារាង និងណាត្រូវការទីតាំង?
- តើ within intersects និង touches ខុសគ្នាដូចម្ដេច?
- តើផ្សំលក្ខខណ្ឌច្រើនតាមលំដាប់ណា?

## ៩.៣. ទ្រឹស្ដីស្នូល

### ៩.៣.១. សំណួរតាមគុណលក្ខណៈ

សំណួរតាមគុណលក្ខណៈ ជ្រើសវត្ថុដោយពិនិត្យតែតម្លៃក្នុងតារាង។

| ប្រមាណវិធី | ឧទាហរណ៍ | អត្ថន័យ |
|---|---|---|
| `=` `<>` | `"SCHOOL_TYP" = 'Primary'` | ស្មើ មិនស្មើ |
| `>` `>=` `<` `<=` | `"TOTPOP" > 3000` | ប្រៀបធៀបលេខ |
| `AND` `OR` `NOT` | `"Location" = 'Rural' AND "SCHOOL_TYP" = 'Primary'` | ផ្សំលក្ខខណ្ឌ |
| `IN` | `"SCHOOL_TYP" IN ('Lycee G7-12', 'Lycee G10-12')` | ស្មើតម្លៃណាមួយក្នុងបញ្ជី |
| `LIKE` `ILIKE` | `"SCHOOL_NAM" ILIKE '%chrey%'` | ផ្គូផ្គងលំនាំ (`%` = តួអក្សរណាក៏បាន · ILIKE មិនប្រកាន់អក្សរធំតូច) |
| `IS NULL` | `"Name" IS NULL` | វាលទទេ |
| អនុគមន៍ | `left("VILL_CODE", 2) = '04'` | ២ តួដំបូង |

ប្រុងប្រយ័ត្នលំដាប់ `AND` និង `OR`៖ `A OR B AND C` មានន័យថា `A OR (B AND C)`។ ប្រើវង់ក្រចកជានិច្ច៖ `("SCHOOL_TYP" = 'Primary' OR "SCHOOL_TYP" = 'Pre school') AND "Location" = 'Rural'`។

### ៩.៣.២. ទំនាក់ទំនងលំហ

សំណួរតាមលំហ ជ្រើសវត្ថុក្នុងស្រទាប់មួយ ដោយប្រៀបធៀបធរណីមាត្ររបស់វាជាមួយវត្ថុក្នុងស្រទាប់មួយទៀត។ ទំនាក់ទំនងទាំងនេះហៅថា **predicates** ហើយកំណត់ដោយគំរូ DE-9IM ដែលពិនិត្យ **ផ្ទៃខាងក្នុង** និង **ព្រំ** នៃវត្ថុទាំងពីរ។

| Predicate | ពិតពេល | ឧទាហរណ៍សំណួរ |
|---|---|---|
| **intersects** | មានចំណុចរួមណាមួយ (ខាងក្នុង ឬព្រំ) | ផ្លូវណាខ្លះឆ្លងកាត់ឃុំនេះ? |
| **disjoint** | គ្មានចំណុចរួមសោះ (ផ្ទុយពី intersects) | ភូមិណាខ្លះនៅក្រៅបាហ្វ័រ? |
| **within** | A នៅក្នុង B ទាំងស្រុង | សាលាណាខ្លះនៅក្នុងខេត្ត? |
| **contains** | B នៅក្នុង A ទាំងស្រុង | ឃុំណាខ្លះមានមណ្ឌលសុខភាព? |
| **touches** | ប៉ះតែព្រំ ខាងក្នុងមិនត្រួត | ឃុំណាខ្លះជាប់ព្រំឃុំនេះ? |
| **overlaps** | ខាងក្នុងត្រួតមួយផ្នែក ប្រភេទធរណីមាត្រដូចគ្នា | តំបន់ការពារណាត្រួតលើដីសម្បទាន? |
| **equals** | ធរណីមាត្រដូចគ្នាទាំងស្រុង | រកវត្ថុស្ទួន |

ចំណុចសំខាន់៖ **touches ក៏ជា intersects** ដែរ។ បើអ្នកជ្រើស «ឃុំដែល intersect ឃុំខ្សាម» អ្នកនឹងបានឃុំជិតខាង **និងឃុំខ្សាមខ្លួនឯង**។

### ៩.៣.៣. សំណួរតាមចម្ងាយ

សំណួរជាច្រើនសួរពី **ភាពជិត** មិនមែនការប៉ះទេ៖ «សាលាក្នុងចម្ងាយ ១ គម ពីផ្លូវជាតិ»។

QGIS មានវិធីពីរ៖

- **Select within distance** ជ្រើសដោយផ្ទាល់ តាមចម្ងាយពីវត្ថុក្នុងស្រទាប់មួយទៀត។
- **Buffer** បន្ទាប់មក **Select by Location (intersects/within)** ដែលបង្កើតស្រទាប់បាហ្វ័រដែលអាចមើល និងប្រើឡើងវិញបាន ([មេរៀនទី១០](lesson-10.md))។

ចម្ងាយត្រូវគណនាក្នុង CRS ដែលមានឯកតាម៉ែត្រ (ឧ. EPSG:32648)។ បើស្រទាប់នៅក្នុង EPSG:4326 «១០០០» មានន័យថា ១ ០០០ ដឺក្រេ។

### ៩.៣.៤. ការផ្សំសំណួរ និងលំដាប់

ឧបករណ៍ជ្រើសក្នុង QGIS មានជម្រើស **Modify current selection**៖

| ជម្រើស | អត្ថន័យតក្កវិជ្ជា |
|---|---|
| creating new selection | ចាប់ផ្ដើមថ្មី |
| adding to current selection | OR |
| removing from current selection | AND NOT |
| selecting within current selection | AND |

ឧទាហរណ៍ «សាលាបឋមសិក្សាក្នុងតំបន់ជំនន់»៖

1. Select by Location៖ សាលា **within** ជំនន់ → creating new selection
2. Select by expression៖ `"SCHOOL_TYP" = 'Primary'` → **selecting within current selection** (Filter current selection)

លទ្ធផលដូចគ្នា ទោះធ្វើតាមលំដាប់ផ្ទុយក៏ដោយ។ ប៉ុន្តែការធ្វើសំណួរគុណលក្ខណៈមុន (លឿន) ជួយកាត់បន្ថយវត្ថុសម្រាប់សំណួរលំហ (យឺត) ក្នុងទិន្នន័យធំ។

!!! danger "កំហុសទូទៅបំផុត"
    ភ្លេចប្ដូរជម្រើសពី «creating new selection» ធ្វើឲ្យជំហានទីពីរលុបជំហានទីមួយ ដោយគ្មានសារព្រមាន។ ពិនិត្យចំនួនវត្ថុដែលបានជ្រើសបន្ទាប់ពីជំហាននីមួយៗជានិច្ច។

### ៩.៣.៥. គុណលក្ខណៈ ទល់នឹង ទីតាំង

សំណួរ «សាលាណាខ្លះនៅខេត្តកំពង់ឆ្នាំង?» អាចឆ្លើយបានពីរវិធី៖

| វិធី | កន្សោម | លទ្ធផល |
|---|---|---:|
| គុណលក្ខណៈ | `"PROVINCE" = 'Kampong Chhnang'` | ៤១៦ |
| ទីតាំង | សាលា **within** ព្រំខេត្ត KH04 | ៤១៥ |

ភាពខុសគ្នាមកពីសាលា Yukunthor ដែលវាល `PROVINCE` និងទីតាំងមិនស៊ីគ្នា ([មេរៀនទី៨](lesson-08.md))។ គ្មានវិធីណា «ត្រឹមត្រូវជានិច្ច» ទេ៖ គុណលក្ខណៈអាចវាយខុស ឯទីតាំងអាចវាស់ខុស ឬព្រំដែនអាចជាកំណែផ្សេង។ ពេលវិធីទាំងពីរខុសគ្នា ត្រូវពិនិត្យករណីនោះម្ដងមួយៗ។

## ៩.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «within និង intersects ដូចគ្នា»**
within តម្រូវឲ្យនៅខាងក្នុងទាំងស្រុង។ intersects ពិតភ្លាមពេលមានចំណុចរួមមួយ រួមទាំងការប៉ះព្រំ។ សម្រាប់ចំណុចលើព្រំពហុកោណ within មិនពិតទេ។

**២. «touches មិនមែនជា intersects»**
touches គឺជាករណីពិសេសនៃ intersects។ ឃុំជិតខាងដែលប៉ះព្រំ នឹងត្រូវជ្រើសដោយ intersects ដែរ។

**៣. «សំណួរតាមលំហ តែងត្រឹមត្រូវជាងគុណលក្ខណៈ»**
ទីតាំងក៏អាចខុស ហើយព្រំដែនអាចជាកំណែផ្សេង។ ពេលវិធីទាំងពីរខុសគ្នា ត្រូវស៊ើបអង្កេត។

**៤. «ចម្ងាយ ១០០០ គឺ ១ គម ជានិច្ច»**
ឯកតាអាស្រ័យលើ CRS។ ក្នុង EPSG:4326 ឯកតាគឺដឺក្រេ។

**៥. «ធ្វើការជ្រើសម្ដងទៀត រក្សាលទ្ធផលមុន»**
ជម្រើសលំនាំដើម «creating new selection» លុបលទ្ធផលមុន។ ត្រូវជ្រើសជម្រើសត្រឹមត្រូវ ឬរក្សាទុកលទ្ធផលជាស្រទាប់។

## ៩.៧. សេចក្ដីសង្ខេបមេរៀន

សំណួរតាមគុណលក្ខណៈ ពិនិត្យតម្លៃក្នុងតារាង ដោយប្រើប្រមាណវិធីប្រៀបធៀប តក្កវិជ្ជា និងអនុគមន៍។ សំណួរតាមលំហ ពិនិត្យទំនាក់ទំនងធរណីមាត្រ៖ intersects within contains touches disjoint overlaps និងចម្ងាយ។

សំណួរពិតច្រើនតែផ្សំទាំងពីរ ដោយប្រើជម្រើស Modify current selection។ លទ្ធផលពីគុណលក្ខណៈ និងពីទីតាំង អាចខុសគ្នា ហើយភាពខុសគ្នានោះជាសញ្ញាឲ្យពិនិត្យគុណភាពទិន្នន័យ។

!!! abstract "គំនិតស្នូលនៃមេរៀន"
    សំណួរត្រឹមត្រូវ ចាប់ផ្ដើមពីការបកប្រែពាក្យធម្មតា («ក្នុង» «ជិត» «ជាប់») ទៅជាទំនាក់ទំនងលំហជាក់លាក់ ហើយពាក្យតែមួយអាចមានន័យច្រើនយ៉ាង។

## ៩.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. បែងចែកសំណួរតាមគុណលក្ខណៈ និងតាមលំហ ដោយលើកឧទាហរណ៍មួយសម្រាប់នីមួយៗ។

3. ហេតុអ្វីសំណួរ «ឃុំដែល intersect ឃុំខ្សាម» ផ្ដល់លទ្ធផលច្រើនជាង touches មួយ?
4. `LIKE` និង `ILIKE` ខុសគ្នាដូចម្ដេច? `%` មានន័យអ្វី?
5. ពន្យល់ជម្រើស Modify current selection ទាំងបួន ជាប្រមាណវិធីតក្កវិជ្ជា។

### ខ. សំណួរអនុវត្តគោលគំនិត

6. សរសេរកន្សោមជ្រើសភូមិក្នុងខេត្តកំពង់ឆ្នាំងដែលមានអក្ខរកម្មទាបជាង ៦០% ឬមានប្រជាជនលើស ៣ ០០០ នាក់។
7. បកប្រែសំណួរ «មណ្ឌលសុខភាពដែលនៅជាប់ទន្លេ» ទៅជាសំណួរលំហ។ តើមានការបកប្រែប៉ុន្មានយ៉ាង ហើយមួយណាសមហេតុផល?
8. រៀបរាប់ជំហានរកឃុំដែលគ្មានសាលាបឋមសិក្សាសោះ។
9. ក្រោយសំណួរពីរជំហាន អ្នកបានសាលា ៤១៥ ជំនួសឲ្យ ៦៥។ តើអ្នកទំនងជាធ្វើកំហុសអ្វី?
10. ពន្យល់ថាហេតុអ្វីផ្លូវមួយខ្សែអាច intersect ប៉ុន្តែមិន within ឃុំណាមួយ ហើយរឿងនេះប៉ះពាល់ដល់ការគណនាប្រវែងផ្លូវតាមឃុំដូចម្ដេច។

### គ. កិច្ចការខ្លី

សរសេរសំណួរ GIS ចំនួន ៥ សម្រាប់ខេត្តរបស់អ្នក ដែលអាចឆ្លើយបានដោយសំណុំទិន្នន័យ `Cambodia`។ សម្រាប់នីមួយៗ៖ សំណួរជាភាសាធម្មតា · ប្រភេទ (គុណលក្ខណៈ លំហ ឬផ្សំ) · ស្រទាប់ · កន្សោម ឬ predicate · ជម្រើស Modify selection · ការបកប្រែខុសដែលអាចកើត។

សំណួរតាមចម្ងាយក្នុងមេរៀននេះ គ្រាន់តែជ្រើសវត្ថុ។ ប៉ុន្តែអ្នកសម្រេចចិត្តច្រើនតែចង់បាន **តំបន់** ដែលស្ថិតក្នុងចម្ងាយមួយ ឬចម្ងាយពិតប្រាកដទៅសេវាជិតបំផុត។ ចូរបញ្ចប់ដោយសួរ៖

> «តើភូមិណាខ្លះនៅឆ្ងាយពីមណ្ឌលសុខភាពជាង ៥ គីឡូម៉ែត្រ ហើយមានប្រជាជនប៉ុន្មាន?»

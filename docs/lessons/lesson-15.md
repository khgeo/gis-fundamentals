គម្រោងបញ្ចប់វគ្គ គឺជាឱកាសដើម្បីបញ្ចូលអ្វីដែលបានរៀនទាំង ១៤ មេរៀន ទៅក្នុងការឆ្លើយសំណួរពិតមួយអំពីកម្ពុជា។

## ១៥.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. រៀបចំរចនាសម្ព័ន្ធថត ឈ្មោះឯកសារ និងទម្រង់ទិន្នន័យសម្រាប់គម្រោង GIS។
2. ពន្យល់ផ្លូវ relative និងការខ្ចប់គម្រោងឲ្យចល័តបាន។
3. ពន្យល់ភាពអាចធ្វើឡើងវិញបាន និងឧបករណ៍ដែលជួយ (Model Designer ប្រវត្តិ Processing)។
4. ពិពណ៌នាវិធីចែករំលែកផែនទី និងទិន្នន័យ ព្រមទាំងការពិចារណាអាជ្ញាបណ្ណ ឯកជនភាព និងសីលធម៌។
5. រៀបចំសំណើគម្រោងបញ្ចប់វគ្គដែលមានសំណួរ ទិន្នន័យ វិធីសាស្ត្រ និងផែនការពេល។

## ១៥.២. ស្ថានភាពបើកមេរៀន៖ គម្រោងដែលបើកមិនបាន

និស្សិតម្នាក់បញ្ចប់ការវិភាគភាពងាយស្រួលទៅមណ្ឌលសុខភាព។ គាត់ផ្ញើឯកសារ `final (2).qgz` តាម Telegram ទៅគ្រូ។ ពេលគ្រូបើក QGIS បង្ហាញប្រអប់ «Unavailable layers» ចំនួន ១២ ស្រទាប់ ព្រោះស្រទាប់ទាំងអស់ចង្អុលទៅ `C:\Users\Student\Desktop\គម្រោង GIS\...` ដែលមិនមាននៅលើកុំព្យូទ័រគ្រូ។

ក្រោយផ្ញើថតទាំងមូលម្ដងទៀត ផែនទីបើកបាន ប៉ុន្តែគ្រូមិនដឹងថាស្រទាប់ `buffer_new_ok.shp` បង្កើតដោយឧបករណ៍អ្វី ចម្ងាយប៉ុន្មាន ពីទិន្នន័យណា។ និស្សិតខ្លួនឯងក៏ចាំមិនបានដែរ។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- តើរៀបចំគម្រោងយ៉ាងណាឲ្យបើកបាននៅគ្រប់កុំព្យូទ័រ?
- តើកត់ត្រាការវិភាគយ៉ាងណាឲ្យអ្នកផ្សេង (និងខ្លួនឯង) ធ្វើឡើងវិញបាន?
- តើចែករំលែកផែនទីដោយទទួលខុសត្រូវដូចម្ដេច?

### ១៥.៣.១. រចនាសម្ព័ន្ធគម្រោង និងឈ្មោះឯកសារ

គម្រោងល្អចាប់ផ្ដើមពីថតដែលមានរចនាសម្ព័ន្ធច្បាស់៖

### ១៥.៣.២. ផ្លូវ relative និងការខ្ចប់គម្រោង

ឯកសារ `.qgz` មិនមានទិន្នន័យទេ។ វារក្សាទុក **ផ្លូវ** ទៅទិន្នន័យ។

| ផ្លូវ | ឧទាហរណ៍ | ពេលផ្ញើ |
|---|---|---|
| Absolute | `C:/Users/Student/Desktop/data/villages.gpkg` | ខូច លុះត្រាកុំព្យូទ័រថ្មីមានផ្លូវដូចគ្នា |
| **Relative** | `data/processed/villages.gpkg` | ធ្វើការ បើផ្ញើថតទាំងមូល |

### ១៥.៣.៣. ភាពអាចធ្វើឡើងវិញបាន

**ភាពអាចធ្វើឡើងវិញបាន (Reproducibility)** មានន័យថា អ្នកផ្សេងដែលមានទិន្នន័យដូចគ្នា និងការពិពណ៌នារបស់អ្នក អាចទទួលបានលទ្ធផលដូចគ្នា។

ឧបករណ៍ក្នុង QGIS៖

- **Processing History** (Processing → History)៖ កំណត់ត្រាឧបករណ៍ទាំងអស់ដែលបានដំណើរការ ជាមួយប៉ារ៉ាម៉ែត្រពេញលេញ។ អាចចម្លងជាកូដ Python បាន។
- **Model Designer**៖ គូរលំហូរការងារ (ឧ. Extract → Buffer → Select by Location → Statistics) ជាក្រាហ្វ ហើយដំណើរការឡើងវិញជាមួយទិន្នន័យថ្មី ឬខេត្តថ្មី ដោយចុចតែម្ដង។
- **README និងមេតាទិន្នន័យ**៖ ពិពណ៌នាប្រភព ជំហាន និងការសម្រេចចិត្ត ([មេរៀនទី៨](lesson-08.md))។

មុនចែករំលែក សួរ៖

1. **អាជ្ញាបណ្ណ**៖ ខ្ញុំមានសិទ្ធិចែកចាយទិន្នន័យនេះបន្តឬទេ? តើត្រូវដកស្រង់ដូចម្ដេច?
2. **ឯកជនភាព**៖ តើមានទីតាំងផ្ទះ ឈ្មោះមនុស្ស ឬព័ត៌មានសុខភាពដែលអាចកំណត់អត្តសញ្ញាណបុគ្គលឬទេ? ត្រូវសរុបតាមភូមិ ឬឃុំ ឬរំកិលទីតាំង។
3. **សុវត្ថិភាព**៖ តើផែនទីអាចបង្កគ្រោះថ្នាក់ឬទេ (ទីតាំងសត្វកម្រ ព្រៃដែលអាចកាប់)?
4. **ការបកស្រាយ**៖ តើផែនទីអាចត្រូវបានយល់ខុសដោយគ្មានដែនកំណត់ដែលអមជាមួយឬទេ?

### ១៥.៣.៥. គម្រោងបញ្ចប់វគ្គ

8. អ្នកធ្វើផែនទីទីតាំងផ្ទះអ្នកជំងឺរបេងក្នុងឃុំមួយ។ ពិពណ៌នាវិធីចែករំលែកលទ្ធផលដោយការពារឯកជនភាព។

### ខ. ការភ្ជាប់ទៅមេរៀនបន្ទាប់

នេះជាមេរៀនចុងក្រោយនៃ *មូលដ្ឋានគ្រឹះនៃប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ*។ ចូរបញ្ចប់ដោយរំលឹកខ្សែស្រឡាយនៃវគ្គទាំងមូល៖ **តំណាង** (មេរៀនទី២–៥) → **ប្រមូល និងពិនិត្យ** (មេរៀនទី៦–៨) → **វិភាគ** (មេរៀនទី៩–១៤) → **ចែករំលែកដោយទទួលខុសត្រូវ** (មេរៀនទី១៥)។

សៀវភៅទី៣៖ *ការចាប់សញ្ញាពីចម្ងាយ* នឹងបង្រៀនពីរបៀបបង្កើតស្រទាប់ថ្មី ដូចជាក្រប់ដី និងទឹកជំនន់ ដោយខ្លួនឯង ពីរូបភាពផ្កាយរណប។

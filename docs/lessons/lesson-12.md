# មេរៀនទី១២៖ ការវិភាគរ៉ាស្ទ័រ និងពីជគណិតផែនទី

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ១២ ក្នុងចំណោម ១៥

[មេរៀនទី៣](lesson-03.md) បានណែនាំរ៉ាស្ទ័រជាគំរូទិន្នន័យ។ មេរៀននេះប្រើរ៉ាស្ទ័រសម្រាប់ **ការវិភាគ**។ ពេលស្រទាប់ទាំងអស់ចែករំលែកក្រឡាដូចគ្នា ការត្រួតស្រទាប់ក្លាយជាលេខនព្វន្ធ៖ ក្រឡានីមួយៗបូក ដក គុណ ឬប្រៀបធៀបជាមួយក្រឡានៅទីតាំងដដែលក្នុងស្រទាប់ផ្សេង។

ភាសានៃការគណនានេះហៅថា **ពីជគណិតផែនទី (Map algebra)**។ យើងនឹងសិក្សាប្រតិបត្តិការបួនកម្រិត៖ ក្នុងក្រឡា ជិតខាង តាមតំបន់ និងទូទាំងស្រទាប់។

## ១២.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. ពន្យល់លក្ខខណ្ឌតម្រឹមរ៉ាស្ទ័រ៖ CRS ទំហំក្រឡា វិសាលភាព និងការតម្រឹមក្រឡា។
2. បែងចែកប្រតិបត្តិការ Local Focal Zonal និង Global ដោយឧទាហរណ៍។
3. សរសេរកន្សោម Raster Calculator ដែលប្រើនព្វន្ធ ប្រៀបធៀប និងតក្កវិជ្ជា។
4. ពន្យល់ការចាត់ថ្នាក់ឡើងវិញ (Reclassify) និងរ៉ាស្ទ័រចម្ងាយ។
5. ពន្យល់ការរីករាលដាលនៃ NoData និងជ្រើសវិធី Resampling ត្រឹមត្រូវ។

## ១២.២. ស្ថានភាពបើកមេរៀន៖ ស្រែប៉ុន្មានហិកតាលិចទឹក?

ក្រសួងកសិកម្មចង់ដឹងថាក្នុងខេត្តកំពង់ឆ្នាំង ដីកសិកម្មប៉ុន្មានហិកតាស្ថិតក្នុងវិសាលភាពទឹកជំនន់ឆ្នាំ ២០១១ និងប៉ុន្មានហិកតាដែលនៅឆ្ងាយពីមណ្ឌលសុខភាពជាង ៥ គីឡូម៉ែត្រ ដែលកសិករពិបាកទទួលសេវាពេលមានគ្រោះទឹកជំនន់។

ដោយវ៉ិចទ័រ ការងារនេះត្រូវការ Intersection ច្រើនជំហាន និងបាហ្វ័រ។ ដោយរ៉ាស្ទ័រ ១០០ ម៉ែត្រ វាក្លាយជាកន្សោមតែមួយបន្ទាត់៖

```text
("agri@1" = 1) AND ("flood@1" = 1) AND ("hc_dist@1" > 5000)
```

សំណួរដែលមេរៀននេះឆ្លើយ៖

- ហេតុអ្វីកន្សោមបែបនេះធ្វើការបាន?
- តើរ៉ាស្ទ័រត្រូវរៀបចំយ៉ាងណាមុនគណនា?
- ក្រៅពីក្រឡាទល់ក្រឡា តើការវិភាគរ៉ាស្ទ័រអាចធ្វើអ្វីទៀត?

## ១២.៣. ទ្រឹស្ដីស្នូល

### ១២.៣.១. លក្ខខណ្ឌតម្រឹមរ៉ាស្ទ័រ

ពីជគណិតផែនទីគណនាក្រឡាទល់ក្រឡា។ ដូច្នេះរ៉ាស្ទ័របញ្ចូលទាំងអស់ត្រូវមាន៖

| លក្ខខណ្ឌ | បើមិនដូចគ្នា |
|---|---|
| CRS ដូចគ្នា | ក្រឡាដែល «ត្រូវគ្នា» មិនមែនជាទីតាំងដដែល |
| ទំហំក្រឡាដូចគ្នា | កម្មវិធី resample ដោយស្វ័យប្រវត្តិ តាមវិធីដែលអ្នកមិនបានជ្រើស |
| វិសាលភាពដូចគ្នា | លទ្ធផលត្រូវកាត់ ឬបំពេញ NoData |
| ការតម្រឹមក្រឡា (snap) | ក្រឡារំកិលពាក់កណ្ដាល ធ្វើឲ្យព្រំដែនរំកិល |

វិធីងាយបំផុត៖ កំណត់ **ក្រឡាគោល** មួយ (ទំហំ និងវិសាលភាព) ហើយបង្កើត ឬ Resample រ៉ាស្ទ័រទាំងអស់ទៅតាមក្រឡានោះ។ ក្រឡា ១០០ × ១០០ ម មានផ្ទៃ ១ ហិកតា ដែលធ្វើឲ្យការរាប់ក្រឡាស្មើផ្ទៃជាហិកតា។

**Resampling** ពេលប្ដូរទំហំក្រឡា៖

| វិធី | ប្រើសម្រាប់ | ហេតុផល |
|---|---|---|
| Nearest neighbour | រ៉ាស្ទ័រថ្នាក់ (ក្រប់ដី) | មិនបង្កើតលេខកូដថ្មី |
| Bilinear · Cubic | រ៉ាស្ទ័របន្ត (កម្ពស់ សីតុណ្ហភាព) | ផ្ដល់តម្លៃរលោង |
| Average · Mode | បង្រួមក្រឡា (ពី ១០ ម ទៅ ១០០ ម) | សង្ខេបក្រឡាតូចៗ |

### ១២.៣.២. ប្រតិបត្តិការបួនកម្រិត

| កម្រិត | ក្រឡាលទ្ធផលពឹងលើ | ឧទាហរណ៍ |
|---|---|---|
| **Local** (ក្នុងក្រឡា) | តែក្រឡានៅទីតាំងដដែល ក្នុងស្រទាប់មួយ ឬច្រើន | `"dem@1" * 3.28` · `("agri@1" = 1) AND ("flood@1" = 1)` |
| **Focal** (ជិតខាង) | ក្រឡា និងក្រឡាជុំវិញ (ឧ. ៣×៣) | មធ្យមផ្លាស់ទី · ជម្រាលពី DEM |
| **Zonal** (តាមតំបន់) | ក្រឡាទាំងអស់ដែលស្ថិតក្នុងតំបន់ដូចគ្នា | ចម្ងាយមធ្យមតាមស្រុក · កម្ពស់អតិបរមាតាមឃុំ |
| **Global** (ទូទាំង) | ក្រឡាទាំងអស់ ឬទីតាំងលក្ខណៈ | ចម្ងាយពីមណ្ឌលសុខភាពជិតបំផុត · មធ្យមទាំងស្រទាប់ |

!!! example "ពិសោធន៍៖ ពីជគណិតផែនទី"
    ជ្រើសប្រតិបត្តិការ ហើយចុចលើក្រឡាលទ្ធផល ដើម្បីមើលក្រឡាដែលប្រើក្នុងការគណនា។ សង្កេតក្រឡា NoData (ND) ក្នុងប្រតិបត្តិការ Local និង Focal។

### ១២.៣.៣. Raster Calculator និងតក្កវិជ្ជា

**Raster Calculator** គណនាកន្សោមលើក្រឡានីមួយៗ៖

| ប្រភេទ | កន្សោម | លទ្ធផល |
|---|---|---|
| នព្វន្ធ | `"a@1" + "b@1"` · `"dem@1" / 1000` | តម្លៃថ្មី |
| ប្រៀបធៀប | `"hc_dist@1" > 5000` | ១ (ពិត) ឬ ០ (មិនពិត) |
| តក្កវិជ្ជា | `("agri@1" = 1) AND ("flood@1" = 1)` | ១ ឬ ០ |
| លក្ខខណ្ឌជាគុណ | `"suit@1" * ("ok@1" = 1)` | តម្លៃ ឬ ០ កន្លែងហាមឃាត់ |
| អនុគមន៍ | `min(1, "d@1" / 3000)` | កំណត់ដែនខាងលើ |

`"agri@1"` មានន័យថា band ទី១ នៃរ៉ាស្ទ័រ `agri`។ រ៉ាស្ទ័រ ០/១ (Boolean) ជាឧបករណ៍ដ៏មានឥទ្ធិពល ព្រោះការគុណរ៉ាស្ទ័រ ០/១ ស្មើនឹង AND ហើយការរាប់ក្រឡាតម្លៃ ១ ស្មើនឹងផ្ទៃ។

**ការចាត់ថ្នាក់ឡើងវិញ (Reclassify)** ប្ដូរតម្លៃ ឬជួរតម្លៃ ទៅជាតម្លៃថ្មី ឧ. ចម្ងាយ ០–២ ០០០ ម → ១ · ២ ០០០–៥ ០០០ → ២ · លើស ៥ ០០០ → ៣។ វាជាជំហានសំខាន់មុនការវិភាគសមស្របភាព ([មេរៀនទី១៤](lesson-14.md))។

### ១២.៣.៤. រ៉ាស្ទ័រចម្ងាយ និងការបម្លែងពីវ៉ិចទ័រ

ទិន្នន័យវគ្គសិក្សាភាគច្រើនជាវ៉ិចទ័រ។ ដើម្បីវិភាគរ៉ាស្ទ័រ ត្រូវ៖

1. **Rasterize** ពហុកោណ (ស្រែ ជំនន់) ជារ៉ាស្ទ័រ ០/១ ([មេរៀនទី៣](lesson-03.md))។
2. **Proximity (Raster distance)** ពីក្រឡាគោលដៅ (មណ្ឌលសុខភាព ផ្លូវ)៖ ក្រឡានីមួយៗទទួលចម្ងាយបន្ទាត់ត្រង់ទៅក្រឡាគោលដៅជិតបំផុត។
3. **Zonal statistics** សង្ខេបរ៉ាស្ទ័រតាមពហុកោណ (ស្រុក ឃុំ)។

រ៉ាស្ទ័រចម្ងាយប្រហាក់ប្រហែលការវិភាគចម្ងាយវ៉ិចទ័រ ([មេរៀនទី១០](lesson-10.md)) ប៉ុន្តែគ្របដណ្ដប់ **គ្រប់ទីតាំង** មិនមែនតែភូមិទេ។ ភាពត្រឹមត្រូវកំណត់ដោយទំហំក្រឡា៖ ក្រឡា ១០០ ម ធ្វើឲ្យចម្ងាយខុសរហូតដល់ប្រហែល ៧០ ម។

បើចង់បានចម្ងាយដែលគិតពីការលំបាកធ្វើដំណើរ (ទឹក ភ្នំ ផ្លូវ) ប្រើ **Cost distance** ដែលក្រឡានីមួយៗមានតម្លៃ «ថ្លៃ» ក្នុងការឆ្លងកាត់។

### ១២.៣.៥. NoData ក្នុងការគណនា

ក្នុងការគណនា Local ភាគច្រើន **NoData + តម្លៃណាក៏ដោយ = NoData**។ ក្រឡាតែមួយដែលគ្មានទិន្នន័យក្នុងស្រទាប់មួយ ធ្វើឲ្យក្រឡាលទ្ធផលគ្មានទិន្នន័យ។

បញ្ហាទូទៅ៖

- Rasterize ដោយកំណត់ NoData = ០ ធ្វើឲ្យ «មិនមែនស្រែ» និង «គ្មានទិន្នន័យ» ក្លាយជារឿងតែមួយ។ ក្នុងករណីខ្លះល្អ ក្នុងករណីខ្លះបំភាន់។
- ក្រឡានៅក្រៅព្រំខេត្ត ដែលមានតម្លៃ ០ ជំនួសឲ្យ NoData ធ្វើឲ្យស្ថិតិ Zonal ខុស។
- ក្នុង Focal ក្រឡានៅគែមរ៉ាស្ទ័រ មានក្រឡាជិតខាងតិច។

ច្បាប់៖ ត្រូវមាន **របាំងតំបន់សិក្សា** (ឧ. `prov.tif` = ១ ក្នុងខេត្ត) ហើយបញ្ចូលក្នុងកន្សោម `AND ("prov@1" = 1)` ជានិច្ច។

## ១២.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ស្រែលិចទឹក និងឆ្ងាយពីមណ្ឌលសុខភាព ខេត្តកំពង់ឆ្នាំង

រ៉ាស្ទ័រទាំងអស់មានក្រឡា ១០០ ម (= ១ ហ.ត) វិសាលភាពដូចគ្នា (ខេត្ត + ១០ គម) និង EPSG:32648 (ដូច[លំហាត់ទី១២](../workbook/lab-12.md))។

### ជំហានទី១៖ រៀបចំរ៉ាស្ទ័រ

`prov` (ខេត្ត = ១) · `agri` (ដីកសិកម្មឆ្នាំ ២០០៣ = ១) · `flood` (ជំនន់ ២០១១ ក្នុងខេត្ត = ១) · `hc_dist` (ចម្ងាយពីមណ្ឌលសុខភាពជិតបំផុត ទូទាំងប្រទេស ជាម៉ែត្រ)។ ដីកសិកម្ម = **១៧០ ០១៥** ក្រឡា (ហ.ត) · ជំនន់ក្នុងខេត្ត = **១៦៧ ៧៥៣** ហ.ត (៣១,៧% នៃខេត្ត)។

### ជំហានទី២៖ Local៖ ស្រែលិចទឹក

`("agri@1" = 1) AND ("flood@1" = 1)` → **៥៤ ២៩៦** ហ.ត ស្មើ ៣១,៩% នៃដីកសិកម្ម។

### ជំហានទី៣៖ Global + Local៖ ស្រែឆ្ងាយ

`("agri@1" = 1) AND ("hc_dist@1" > 5000) AND ("prov@1" = 1)` → **៥៦ ០៦៥** ហ.ត។ ចម្ងាយអតិបរមាក្នុងខេត្ត ២៥,៣ គម។

### ជំហានទី៤៖ Zonal៖ ចម្ងាយមធ្យមតាមស្រុក

## ១២.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

## ១២.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. រាយលក្ខខណ្ឌបួនដែលរ៉ាស្ទ័រត្រូវមាន មុនប្រើ Raster Calculator។
2. បែងចែក Local Focal Zonal Global ដោយឧទាហរណ៍មួយសម្រាប់នីមួយៗ។
3. ហេតុអ្វីក្រឡា ១០០ ម ងាយស្រួលសម្រាប់គណនាផ្ទៃ?
4. ពេល Resample រ៉ាស្ទ័រក្រប់ដី ហេតុអ្វីត្រូវប្រើ Nearest neighbour?
5. ពន្យល់ថាហេតុអ្វីកន្សោមត្រូវមាន `AND ("prov@1" = 1)`។

### ខ. សំណួរអនុវត្តគោលគំនិត

6. សរសេរកន្សោមរកក្រឡាដែលជាព្រៃ (`lc` = ២) មានកម្ពស់លើស ២០០ ម (`dem`) និងនៅឆ្ងាយពីផ្លូវជាង ២ គម (`road_dist`)។
7. DEM ៣០ ម និងក្រប់ដី ១០ ម ត្រូវប្រើរួមគ្នា។ តើអ្នកនឹងជ្រើសក្រឡាគោលអ្វី ហើយ Resample ស្រទាប់ណាដោយវិធីអ្វី?
8. ក្នុងពិសោធន៍ Map algebra ក្រឡា NoData មួយធ្វើឲ្យលទ្ធផល Focal នៃក្រឡាជុំវិញខុសដូចម្ដេច? ពន្យល់ដោយផ្អែកលើការគណនាដែលអ្នកឃើញ។
9. រៀបរាប់ជំហានរ៉ាស្ទ័ររកផ្ទៃស្រែលិចទឹកតាមឃុំ ហើយប្រៀបធៀបជាមួយវិធីវ៉ិចទ័រក្នុង[មេរៀនទី១១](lesson-11.md)។
10. ស្ថិតិ Zonal បង្ហាញស្រុកមួយមានចម្ងាយមធ្យម ២,៦ គម។ តើមានន័យថាប្រជាជនស្រុកនោះធ្វើដំណើរ ២,៦ គម ជាមធ្យមឬទេ? ពន្យល់។

### គ. កិច្ចការខ្លី

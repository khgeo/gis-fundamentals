# មេរៀនទី៥៖ មូលទិន្នន័យ ការភ្ជាប់តារាង និង Field Calculator

[មេរៀនទី៤](lesson-04.md) បានបង្ហាញតារាងគុណលក្ខណៈមួយ។ ប៉ុន្តែព័ត៌មានដែលយើងត្រូវការ ច្រើនតែនៅរាយប៉ាយក្នុងឯកសារច្រើន៖ ព្រំឃុំពីស្ថាប័នមួយ ជំរឿនពីវិទ្យាស្ថានជាតិស្ថិតិ និងទិន្នន័យកសិកម្មពីក្រសួងមួយទៀត។

មេរៀននេះបង្រៀនពីរបៀបរៀបចំ **មូលទិន្នន័យ** ភ្ជាប់តារាងតាមវាលរួម និងបង្កើតព័ត៌មានថ្មីដោយ **Field Calculator**។

## ៥.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. ពន្យល់គោលគំនិតមូលទិន្នន័យទំនាក់ទំនង៖ តារាង លេខសម្គាល់ចម្បង និងលេខសម្គាល់បរទេស។
2. ពន្យល់ទំនាក់ទំនងមួយទល់មួយ មួយទល់ច្រើន និងផលប៉ះពាល់ពេលភ្ជាប់តារាង។
3. រៀបចំវាលភ្ជាប់ឲ្យមានទម្រង់ដូចគ្នា និងពិនិត្យកំណត់ត្រាដែលគ្មានដៃគូ។
4. ប្រើ Field Calculator ដើម្បីគណនាផ្ទៃ ដង់ស៊ីតេ ភាគរយ និងចាត់ថ្នាក់។
5. ពន្យល់ហេតុអ្វីផែនទី choropleth ត្រូវប្រើអត្រា ឬដង់ស៊ីតេ មិនមែនចំនួនដុល។

## ៥.២. ស្ថានភាពបើកមេរៀន៖ ជំរឿនមាន ព្រំឃុំក៏មាន ប៉ុន្តែភ្ជាប់មិនបាន

និស្សិតម្នាក់ចង់ធ្វើផែនទីដង់ស៊ីតេប្រជាជនខេត្តកំពង់ឆ្នាំង។ គាត់មានស្រទាប់ `Kh_Commune_area` (ព្រំឃុំ ២០១៩) និងតារាង `Census_Commune` (ជំរឿន ២០០៨)។ គាត់ភ្ជាប់តារាងទាំងពីរតាមលេខកូដឃុំ។ លទ្ធផល៖ **គ្មានកំណត់ត្រាណាមួយត្រូវគ្នាទេ**។

ពេលមើលឲ្យជិត ព្រំឃុំប្រើលេខកូដ `KH040301` ឯជំរឿនប្រើ `040301`។ តួអក្សរពីរ `KH` ធ្វើឲ្យការភ្ជាប់បរាជ័យទាំងស្រុង។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- តើការភ្ជាប់តារាងធ្វើការយ៉ាងដូចម្ដេច?
- តើត្រូវរៀបចំវាលភ្ជាប់ដូចម្ដេច និងពិនិត្យលទ្ធផលយ៉ាងណា?
- ក្រោយភ្ជាប់រួច តើត្រូវគណនាអ្វី ដើម្បីធ្វើផែនទីដែលមិនបំភាន់?

## ៥.៣. ទ្រឹស្ដីស្នូល

### ៥.៣.១. មូលទិន្នន័យទំនាក់ទំនង

**មូលទិន្នន័យ (Database)** គឺជាសំណុំតារាងដែលរៀបចំឲ្យអាចភ្ជាប់គ្នាបាន។ ជំនួសឲ្យការដាក់ព័ត៌មានទាំងអស់ក្នុងតារាងធំមួយ យើងបំបែកតាមប្រធានបទ ហើយភ្ជាប់តាម **វាលរួម**។

- **លេខសម្គាល់ចម្បង (Primary key)**៖ វាលដែលមានតម្លៃតែមួយគត់ក្នុងតារាងមួយ ដូចជា `CommGis` ក្នុងស្រទាប់ឃុំ។
- **លេខសម្គាល់បរទេស (Foreign key)**៖ វាលក្នុងតារាងមួយទៀត ដែលយោងទៅលេខសម្គាល់ចម្បង ដូចជា `COMM_CODE` ក្នុងជំរឿន។

អត្ថប្រយោជន៍៖ ព្រំឃុំអាចប្រើជាមួយជំរឿនឆ្នាំ ២០០៨ ឆ្នាំ ២០១៩ ឬទិន្នន័យកសិកម្ម ដោយមិនចាំបាច់ចម្លងធរណីមាត្រច្រើនដង។ ពេលកែឈ្មោះឃុំ យើងកែតែកន្លែងមួយ។

!!! tip "GeoPackage ជាមូលទិន្នន័យ"
    ឯកសារ `.gpkg` មួយអាចមានស្រទាប់ និងតារាងច្រើន។ វាជាមូលទិន្នន័យ SQLite តូចមួយ ដែលស័ក្ដិសមសម្រាប់គម្រោងនិស្សិតជាង Shapefile ច្រើន។

### ៥.៣.២. ការភ្ជាប់តារាងតាមគុណលក្ខណៈ

**ការភ្ជាប់តារាង (Table join)** បន្ថែមវាលពីតារាងមួយ ទៅតារាងមួយទៀត ដោយផ្គូផ្គងតម្លៃក្នុងវាលរួម។

| ពាក្យ | អត្ថន័យក្នុង QGIS |
|---|---|
| Target layer | ស្រទាប់ដែលទទួលវាលថ្មី (ជាធម្មតាស្រទាប់មានធរណីមាត្រ) |
| Join layer | តារាងដែលផ្ដល់វាល |
| Target field / Join field | វាលដែលត្រូវផ្គូផ្គង |

ការភ្ជាប់ត្រូវគ្នាលុះត្រាតែតម្លៃ **ដូចគ្នាទាំងស្រុង**៖ `KH040301` ≠ `040301` · `040301` ≠ `40301` · `B'er` ≠ `Ph'er` · `Khsam` ≠ `Khsam ` (ដកឃ្លាខាងក្រោយ)។

### ៥.៣.៣. ទំនាក់ទំនងមួយទល់មួយ និងមួយទល់ច្រើន

| ទំនាក់ទំនង | ឧទាហរណ៍ | លទ្ធផលពេលភ្ជាប់ |
|---|---|---|
| **មួយទល់មួយ** | ឃុំមួយ ↔ ជួរជំរឿនមួយ | ងាយស្រួល វាលថ្មីមួយតម្លៃក្នុងមួយឃុំ |
| **ច្រើនទល់មួយ** | ភូមិច្រើន → ឃុំមួយ | ភូមិនីមួយៗទទួលឈ្មោះឃុំដូចគ្នា ត្រឹមត្រូវ |
| **មួយទល់ច្រើន** | ឃុំមួយ ↔ សាលាច្រើន | QGIS ភ្ជាប់ **តែកំណត់ត្រាដំបូង** ព័ត៌មានផ្សេងបាត់ដោយស្ងាត់ |

### ៥.៣.៤. Field Calculator

**Field Calculator** បង្កើត ឬធ្វើបច្ចុប្បន្នភាពវាល ដោយប្រើកន្សោម។ វាលថ្មីអាចគណនាពីវាលផ្សេង ពីធរណីមាត្រ ឬពីអនុគមន៍។

| គោលបំណង | កន្សោម |
|---|---|
| ផ្ទៃ (គម²) | `$area / 1000000` |
| ប្រវែង (គម) | `$length / 1000` |
| ដង់ស៊ីតេ | `"TOTPOP" / ($area / 1000000)` |
| ភាគរយ | `100 * "FEMALES" / "TOTPOP"` |
| ភ្ជាប់អក្សរ | <code>'KH' &#124;&#124; "COMM_CODE"</code> |
| ចាត់ថ្នាក់ | `CASE WHEN "dens" < 100 THEN 'ទាប' ELSE 'ខ្ពស់' END` |
| បំពេញលេខ ០ | `lpad("code", 6, '0')` |

`$area` គណនាពីធរណីមាត្របច្ចុប្បន្ន ដូច្នេះត្រឹមត្រូវជាងវាលផ្ទៃចាស់ៗក្នុងតារាង ដែលអាចមកពីព្រំដែនកំណែផ្សេង។ ពេលចែក ត្រូវប្រុងប្រយ័ត្នការចែកនឹងសូន្យ ឬ NULL។

### ៥.៣.៥. ចំនួនដុល ទល់នឹង អត្រា

ផែនទីពណ៌តាមតំបន់ (**choropleth**) ធ្វើឲ្យភ្នែកមើលផ្ទៃ។ បើយើងដាក់ពណ៌តាម **ចំនួនប្រជាជនដុល** ឃុំធំៗជនបទនឹងមើលទៅ «សំខាន់» ដោយសារតែមានផ្ទៃធំ មិនមែនដោយសារមានមនុស្សក្រាស់ទេ។

ក្បួន៖ ផែនទី choropleth ត្រូវប្រើតម្លៃដែល **ធ្វើឲ្យស្តង់ដារ** រួច៖

- ចែកនឹងផ្ទៃ → ដង់ស៊ីតេ (នាក់/គម²)
- ចែកនឹងចំនួនសរុប → ភាគរយ (% គ្រួសារមានទឹកស្អាត)
- ចែកនឹងចំនួនប្រជាជន → អត្រា (គ្រូពេទ្យក្នុងប្រជាជន ១០ ០០០)

## ៥.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

4. ហេតុអ្វីគួរគណនាផ្ទៃដោយ `$area` ជំនួសឲ្យវាលផ្ទៃក្នុងតារាងជំរឿន?

6. បន្ទាប់ពីភ្ជាប់ជំរឿនខេត្តកំពង់ចាម មានឃុំ ២០ គ្មានដៃគូ។ ចូររាយមូលហេតុដែលអាចកើត និងវិធីពិនិត្យនីមួយៗ។

9. លេខកូដភូមិក្នុងតារាង Excel បាត់លេខ ០ ខាងមុខ (`1020101`)។ សរសេរកន្សោមស្ដារវាឲ្យមាន ៨ ខ្ទង់។

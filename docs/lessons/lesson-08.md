# មេរៀនទី៨៖ គុណភាពទិន្នន័យ កំហុស និងមេតាទិន្នន័យ

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ៨ ក្នុងចំណោម ១៥

គ្មានទិន្នន័យណាឥតកំហុសទេ។ សំណួរមិនមែនថា «ទិន្នន័យនេះមានកំហុសឬទេ?» ទេ ប៉ុន្តែ «កំហុសប្រភេទអ្វី ធំប៉ុណ្ណា ហើយវាប៉ះពាល់ដល់ចម្លើយរបស់ខ្ញុំឬទេ?»

មេរៀននេះរៀបចំគោលគំនិតគុណភាពទិន្នន័យជាធាតុផ្សំ បង្ហាញកំហុសពិតពីសំណុំទិន្នន័យវគ្គសិក្សា ហើយណែនាំ **មេតាទិន្នន័យ** ដែលជាឯកសារប្រាប់អ្នកប្រើពីគុណភាពទាំងនោះ។

---

## ៨.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. បែងចែកភាពត្រឹមត្រូវ (accuracy) និងភាពជាក់លាក់ (precision)។
2. ពន្យល់ធាតុផ្សំនៃគុណភាពទិន្នន័យ៖ ទីតាំង គុណលក្ខណៈ ភាពស៊ីសង្វាក់តក្កវិជ្ជា ភាពពេញលេញ ពេលវេលា និងប្រភពដើម។
3. កំណត់ប្រភពកំហុសក្នុងដំណាក់កាលផ្សេងៗនៃការងារ GIS។
4. ពន្យល់ថាកំហុសរីករាលដាលតាមការវិភាគយ៉ាងដូចម្ដេច។
5. សរសេរមេតាទិន្នន័យមូលដ្ឋានសម្រាប់ស្រទាប់មួយ។

## ៨.២. ស្ថានភាពបើកមេរៀន៖ ខេត្តស្ទឹងត្រែងមានប្រជាជន ២១៤ ពាន់នាក់?

និស្សិតម្នាក់ធ្វើផែនទីប្រជាជនតាមខេត្ត ដោយប្រើចំណុចខេត្តពីស្រទាប់ `Census_Prov_point`។ ផែនទីបង្ហាញថាខេត្តស្ទឹងត្រែងមានផ្ទៃ ២ ៦២២ គម² និងប្រជាជន ២១៤ ៦៣០ នាក់។ គ្រូមើលហើយនិយាយថា «ស្ទឹងត្រែងធំជាងនេះច្រើន ហើយប្រជាជនតិចជាងនេះ»។

ពេលពិនិត្យ តម្លៃទាំងនោះពិតជារបស់ខេត្ត **ព្រះសីហនុ**។ ទីតាំងចំណុចត្រឹមត្រូវ ប៉ុន្តែគុណលក្ខណៈត្រូវបានចម្លងខុស។ ស្រទាប់ `Kh_Province_Boundary` មានតម្លៃត្រឹមត្រូវ (ស្ទឹងត្រែង ១២ ០២១ គម²)។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- តើកំហុសនេះជាប្រភេទអ្វី ហើយធ្លាប់រកឃើញដោយរបៀបណា?
- តើមានកំហុសប្រភេទផ្សេងទៀតអ្វីខ្លះ?
- តើអ្នកផលិតទិន្នន័យគួរប្រាប់អ្នកប្រើពីកំហុសដោយរបៀបណា?

## ៨.៣. ទ្រឹស្ដីស្នូល

### ៨.៣.១. ភាពត្រឹមត្រូវ និងភាពជាក់លាក់

- **ភាពត្រឹមត្រូវ (Accuracy)**៖ តម្លៃវាស់នៅជិតតម្លៃពិតប៉ុណ្ណា។
- **ភាពជាក់លាក់ (Precision)**៖ ការវាស់ម្ដងៗស៊ីគ្នាប៉ុណ្ណា ឬតម្លៃលម្អិតប៉ុណ្ណា (ចំនួនខ្ទង់ទសភាគ)។

ទិន្នន័យអាចជាក់លាក់ ប៉ុន្តែមិនត្រឹមត្រូវ៖ កូអរដោនេ `444095.8736` មានខ្ទង់ទសភាគ ៤ (ជាក់លាក់ដល់ ០,១ មម) ប៉ុន្តែបើវាស់ដោយទូរស័ព្ទ ភាពត្រឹមត្រូវពិតគឺប្រហែល ៥ ម។ ខ្ទង់ទសភាគច្រើន **បង្កើតការជឿជាក់ក្លែងក្លាយ**។

!!! example "ពិសោធន៍៖ ត្រឹមត្រូវ ឬ ជាក់លាក់?"
    ប្ដូរលម្អៀង និងការរាយប៉ាយ។ ករណីណាដែលគ្រោះថ្នាក់បំផុតសម្រាប់អ្នកប្រើទិន្នន័យ ហើយហេតុអ្វី?

### ៨.៣.៣. ប្រភពកំហុសតាមដំណាក់កាល

កំហុសអាចចូលក្នុងគ្រប់ដំណាក់កាលនៃការងារ GIS ([មេរៀនទី១](lesson-01.md))៖

| ដំណាក់កាល | កំហុសទូទៅ |
|---|---|
| ប្រមូល | GPS លម្អៀង · សំណួរស្ទង់មតិមិនច្បាស់ · ផែនទីប្រភពមាត្រដ្ឋានតូច |
| បញ្ចូល | វាយខុស · លេខខ្មែរ · Georeferencing · គូរ undershoot |
| ដំណើរការ | ភ្ជាប់តារាងខុស · CRS ខុស · Rasterize ក្រឡាធំ · ភ្លេចគណនាផ្ទៃឡើងវិញក្រោយ Intersection |
| វិភាគ | វិធីមិនសមនឹងទិន្នន័យ (មធ្យមលើ Nominal) · ឆ្នាំមិនស៊ីគ្នា |
| បង្ហាញ | ចំនួនដុលក្នុង choropleth · ខ្ទង់ទសភាគច្រើនពេក · ពណ៌បំភាន់ |

**កំហុសរីករាលដាល (Error propagation)**៖ ពេលស្រទាប់ពីរដែលមានកំហុសត្រួតគ្នា កំហុសមិនរលាយបាត់ទេ វាបូកបញ្ចូលគ្នា។ ឧទាហរណ៍ ក្នុង[លំហាត់ទី១១](../workbook/lab-11.md) ក្រប់ដីឆ្នាំ ២០០៣ បង្ហាញដីទំនេរ ១២៦ ពាន់ហ.ត ដែលច្រើនជាងឆ្នាំ ១៩៩៧ ប្រហែលប្រាំដង ហើយស្ទើរទាំងអស់ «ត្រឡប់ជាដីកសិកម្មវិញ» នៅឆ្នាំ ២០១៥។ លំនាំបែបនេះទំនងជាភាពខុសគ្នានៃការចាត់ថ្នាក់ មិនមែនការផ្លាស់ប្ដូរលើដីទេ។

### ៨.៣.៤. ការរកកំហុស

វិធីរកកំហុសដែលមិនត្រូវការទិន្នន័យយោងខាងក្រៅ៖

1. **ពិនិត្យតម្លៃតែមួយគត់**៖ លេខកូដស្ទួន (KH18 លេចពីរដង) ឬឈ្មោះថ្នាក់ច្រើនរបៀប។
2. **ពិនិត្យជួរតម្លៃ**៖ ភាគរយលើស ១០០ · ប្រជាជនអវិជ្ជមាន · ជម្រៅ ៥០០ ម។
3. **ពិនិត្យភាពស៊ីគ្នារវាងវាល**៖ `PCODE` ទល់នឹង `PNAME`។
4. **ពិនិត្យភាពស៊ីគ្នារវាងគុណលក្ខណៈ និងទីតាំង**៖ `PROVINCE` ទល់នឹង Select by Location។
5. **ពិនិត្យធរណីមាត្រ**៖ Check Validity · ពហុកោណត្រួតគ្នា · ចន្លោះ។
6. **ពិនិត្យផលបូក**៖ ប្រជាជនភូមិបូកស្មើប្រជាជនខេត្តឬទេ? ក្នុងជំរឿន ២០០៨ ភូមិបូកបាន ១៣ ៣៧១ ៧៨៩ ឯខេត្តបូកបាន ១៣ ៣៩៥ ៦៨២ ដែលខុសគ្នា ២៣ ៨៩៣ នាក់។

ពេលរកឃើញកំហុស៖ **កុំកែទិន្នន័យដើម**។ ធ្វើច្បាប់ចម្លង កែ ហើយកត់ត្រាអ្វីដែលបានកែ ពេលណា និងហេតុអ្វី។

### ៨.៣.៥. មេតាទិន្នន័យ

**មេតាទិន្នន័យ (Metadata)** គឺជា «ទិន្នន័យអំពីទិន្នន័យ»។ វាប្រាប់អ្នកប្រើនាពេលអនាគត (រួមទាំងខ្លួនអ្នកក្នុងរយៈពេល ៦ ខែ) ពីអ្វីដែលពួកគេត្រូវដឹង មុនប្រើស្រទាប់មួយ។

9. ប្រជាជនភូមិបូកតិចជាងប្រជាជនខេត្ត ២៣ ៨៩៣ នាក់។ ស្នើមូលហេតុបីដែលអាចកើត។
10. អ្នកប្រើផ្លូវពី OSM និងភូមិពីជំរឿន ២០០៨។ រាយធាតុផ្សំគុណភាពដែលអាចមានបញ្ហា សម្រាប់ការវិភាគចម្ងាយពីភូមិទៅផ្លូវ។

### គ. កិច្ចការខ្លី

ជ្រើសស្រទាប់មួយពីសំណុំទិន្នន័យ `Cambodia` ដែលមិនបានលើកឡើងក្នុងមេរៀននេះ។ សរសេររបាយការណ៍គុណភាព ១ ទំព័រ តាមធាតុផ្សំទាំងប្រាំមួយ៖ អ្វីដែលអ្នកពិនិត្យ · អ្វីដែលអ្នករកឃើញ · ផលប៉ះពាល់ · ការស្នើកែ។ បញ្ចប់ដោយមេតាទិន្នន័យ ៨ ធាតុ។

# ជំពូក ៣៖ ប្រព័ន្ធយោងកូអរដោនេ និងការព្យាករ

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. ពន្យល់ភាពខុសគ្នារវាង geoid, ellipsoid និង datum
    2. ប្រើកូអរដោនេភូមិសាស្ត្រ និងកូអរដោនេព្យាករ
    3. ជ្រើសរើស CRS សមស្របសម្រាប់ការងារនៅកម្ពុជា
    4. ពន្យល់ប្រភេទនៃការបង្ខូចទ្រង់ទ្រាយ និងផលប៉ះពាល់លើការវាស់

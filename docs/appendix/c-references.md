## ការសិក្សាបន្តបន្ទាប់ពីមុខវិជ្ជានេះ

| ទិសដៅ | អ្វីត្រូវរៀនបន្ត |
|---|---|
| ការស្ទង់ពីចម្ងាយ | ការចាត់ថ្នាក់រូបភាព, សន្ទស្សន៍វិសាលគម, ការតាមដានការផ្លាស់ប្ដូរ |
| GIS ដោយកម្មវិធី | Python / PyQGIS, GDAL, ការសរសេរស្គ្រីបស្វ័យប្រវត្តិ |
| ស្ថិតិលំហ | autocorrelation, hot spot analysis, geostatistics |
| GIS លើពពក | Google Earth Engine, ដំណើរការទិន្នន័យទ្រង់ទ្រាយធំ |
| WebGIS | Leaflet, GeoServer, PostGIS |
| ការរៀនម៉ាស៊ីន | ការចាត់ថ្នាក់ដោយ Random Forest, ការបែងចែកជាផ្នែក (segmentation) |

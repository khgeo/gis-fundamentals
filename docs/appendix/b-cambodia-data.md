# ឧបសម្ព័ន្ធ ខ៖ ទិន្នន័យកម្ពុជា

ឧបសម្ព័ន្ធនេះមានពីរផ្នែក។ **ផ្នែក ក** ពិពណ៌នាសំណុំទិន្នន័យ `Cambodia` ដែលប្រើក្នុងសៀវភៅអនុវត្ត។ **ផ្នែក ខ** ណែនាំប្រភពទិន្នន័យបើកចំហផ្សេងទៀត សម្រាប់គម្រោងផ្ទាល់ខ្លួន។

### បញ្ជីត្រួតពិនិត្យមុនប្រើទិន្នន័យ

មុននឹងយកទិន្នន័យណាមួយមកប្រើ សូមឆ្លើយសំណួរទាំង ៦ នេះ៖

1. **CRS** អ្វី? ត្រូវការបំប្លែងចំណោលទេ?
2. **កាលបរិច្ឆេទ** ណា? នៅទាន់សម័យសម្រាប់សំណួររបស់ខ្ញុំទេ?
3. **គុណភាពបង្ហាញ** ប៉ុន្មាន? សមនឹងមាត្រដ្ឋានផែនទីរបស់ខ្ញុំទេ?
4. **ភាពត្រឹមត្រូវ** ប៉ុន្មាន? មានរបាយការណ៍វាយតម្លៃទេ?
5. **អាជ្ញាបណ្ណ** អ្វី? ខ្ញុំត្រូវដកស្រង់ដូចម្ដេច?
6. **ទិន្នន័យមេតា** មានគ្រប់គ្រាន់ទេ ដើម្បីឲ្យអ្នកដទៃធ្វើម្ដងទៀតបាន?

## គោលដៅសិក្សា (Learning Outcomes)

នៅចុងវគ្គសិក្សា និស្សិតអាច៖

1. **ពន្យល់** អំពីសមាសភាគ និងគោលគំនិតមូលដ្ឋាននៃ GIS និងភាពខុសគ្នារវាងគំរូទិន្នន័យវ៉ិចទ័រ និងរ៉ាស្ទ័រ។
2. **ជ្រើសរើស និងអនុវត្ត** ប្រព័ន្ធយោងកូអរដោនេ (CRS) ត្រឹមត្រូវសម្រាប់ទិន្នន័យកម្ពុជា។
3. **ប្រមូល រៀបចំ និងវាយតម្លៃគុណភាព** ទិន្នន័យភូមិសាស្ត្រពីប្រភពផ្សេងៗ។
4. **អនុវត្ត** ការវិភាគលំហមូលដ្ឋាន (query, buffer, overlay, map algebra, surface analysis) ដើម្បីឆ្លើយសំណួរជាក់ស្ដែង។
5. **រចនា និងផលិត** ផែនទីវិជ្ជាជីវៈដែលមានធាតុផ្សំគ្រប់គ្រាន់ និងអាចអានបាន។
6. **បញ្ចប់** គម្រោងតូចមួយពីទិន្នន័យដើមរហូតដល់ផែនទី និងរបាយការណ៍។

## ការវាយតម្លៃ (Assessment)

| សមាសភាគ | ភាគរយ |
|---|---|
| វត្តមាន និងការចូលរួម | ១០% |
| លំហាត់អនុវត្ត (១៤ លំហាត់) | ២៥% |
| ប្រឡងពាក់កណ្ដាលឆមាស | ២០% |
| គម្រោងបញ្ចប់វគ្គ (ផែនទី + របាយការណ៍ + បទបង្ហាញ) | ២៥% |
| ប្រឡងបញ្ចប់ឆមាស | ២០% |

### លក្ខណៈវិនិច្ឆ័យគម្រោងបញ្ចប់វគ្គ

និស្សិត (ក្រុម ២–៣ នាក់) ជ្រើសរើសបញ្ហាជាក់ស្ដែងមួយនៅកម្ពុជា រួចដោះស្រាយដោយប្រើ GIS៖

| លក្ខណៈវិនិច្ឆ័យ | ពិន្ទុ |
|---|---|
| ភាពច្បាស់លាស់នៃសំណួរស្រាវជ្រាវ | ១៥ |
| ភាពសមស្របនៃទិន្នន័យ និងការចង្អុលប្រភព | ២០ |
| ភាពត្រឹមត្រូវនៃវិធីវិភាគ | ២៥ |
| គុណភាពផែនទី (ធាតុគ្រប់គ្រាន់ អានបាន) | ២៥ |
| របាយការណ៍ និងបទបង្ហាញ | ១៥ |

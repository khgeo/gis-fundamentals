# ជំពូក ១៤៖ Web GIS និងការចែករំលែកទិន្នន័យ

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. ពន្យល់ស្ថាបត្យកម្ម Web GIS
    2. បោះផ្សាយផែនទីអន្តរកម្មលើអ៊ីនធឺណិត
    3. ប្រើសេវាទិន្នន័យលើបណ្ដាញ (WMS, WFS, XYZ)
    4. ពិពណ៌នាតួនាទី GIS លើពពក ដូចជា Google Earth Engine

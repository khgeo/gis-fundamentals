# ជំពូក ១៤ — Web GIS និងការចែករំលែកទិន្នន័យ

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. ពន្យល់ស្ថាបត្យកម្ម Web GIS
    2. បោះផ្សាយផែនទីអន្តរកម្មលើអ៊ីនធឺណិត
    3. ប្រើសេវាទិន្នន័យលើបណ្ដាញ (WMS, WFS, XYZ)
    4. ពិពណ៌នាតួនាទី GIS លើពពក ដូចជា Google Earth Engine

---

## ១៤.១ ស្ថាបត្យកម្ម Web GIS

*គ្រោង៖* ម៉ាស៊ីនភ្ញៀវ–ម៉ាស៊ីនបម្រើ; ក្រឡាផែនទី (map tiles)

## ១៤.២ សេវាបណ្ដាញស្តង់ដារ

*គ្រោង៖* WMS (រូបភាព), WFS (វ៉ិចទ័រ), WMTS/XYZ; ការបន្ថែមក្នុង QGIS

## ១៤.៣ ការបោះផ្សាយផែនទី

*គ្រោង៖* កម្មវិធីបន្ថែម qgis2web (Leaflet/OpenLayers); ការដាក់លើ GitHub Pages

## ១៤.៤ GIS លើពពក

*គ្រោង៖* Google Earth Engine — គោលការណ៍ និងពេលណាគួរប្រើ; ដំណើរការរូបភាពទ្រង់ទ្រាយធំ

## ១៤.៥ ការចែករំលែកទិន្នន័យប្រកបដោយការទទួលខុសត្រូវ

*គ្រោង៖* អាជ្ញាបណ្ណ, ទិន្នន័យមេតា, ភាពឯកជន (ទីតាំងផ្ទះ/ជនរងគ្រោះ)

## ១៤.៦ ការគ្រប់គ្រងគម្រោង

*គ្រោង៖* រចនាសម្ព័ន្ធថត, ផ្លូវទាក់ទង (relative paths), ការបម្រុងទុក, ការប្រើ Git សម្រាប់គម្រោង GIS

# ជំពូក ៧ — ប្រភព និងការប្រមូលទិន្នន័យនៅកម្ពុជា

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. រៀបរាប់ប្រភពទិន្នន័យភូមិសាស្ត្រសំខាន់ៗសម្រាប់កម្ពុជា
    2. វាយតម្លៃភាពសមស្រប និងអាជ្ញាបណ្ណទិន្នន័យ
    3. ប្រមូលទិន្នន័យវាលដោយប្រើ GNSS
    4. ទាញយកទិន្នន័យពី OpenStreetMap និងបណ្ណសារផ្កាយរណបបើកចំហ

---

## ៧.១ ទិន្នន័យបឋម ទល់នឹង ទិន្នន័យទុតិយភូមិ

*គ្រោង៖* ប្រមូលដោយខ្លួនឯង ទល់នឹង ទាញពីអ្នកដទៃ

## ៧.២ ប្រភពរដ្ឋាភិបាលកម្ពុជា

*គ្រោង៖* NIS (ជំរឿន), MLMUPC, MoWRAM, MAFF, NCDM; ការប្រុងប្រយ័ត្នអំពីភាពទាន់សម័យ

## ៧.៣ ប្រភពបើកចំហជាអន្តរជាតិ

*គ្រោង៖* OpenStreetMap, Humanitarian Data Exchange, WorldPop, Global Forest Change, SRTM/Copernicus DEM, ODC (Open Development Cambodia)

## ៧.៤ រូបភាពផ្កាយរណបឥតគិតថ្លៃ

*គ្រោង៖* Sentinel-1/2 (Copernicus), Landsat 8/9 (USGS), MODIS; Copernicus Browser និង USGS EarthExplorer

## ៧.៥ ការប្រមូលដោយ GNSS

*គ្រោង៖* គោលការណ៍ត្រីកោណមាត្រ; ភាពត្រឹមត្រូវនៃទូរស័ព្ទ ទល់នឹង ឧបករណ៍វាស់; ការប្រមូលតាមទម្រង់ (ODK, QField)

## ៧.៦ ដ្រូន និង UAV

*គ្រោង៖* ពេលណាសមស្រប; គោលការណ៍ ortho-mosaic ខ្លីៗ

## ៧.៧ អាជ្ញាបណ្ណ និងសិទ្ធិប្រើប្រាស់

*គ្រោង៖* CC-BY, ODbL (OSM), ការដកស្រង់ប្រភព; ហេតុអ្វីមិនអាចយករូបពី Google Maps ទៅដាក់ក្នុងផែនទីផ្លូវការ

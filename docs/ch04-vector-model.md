# ជំពូក ៤ — គំរូទិន្នន័យវ៉ិចទ័រ

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. រៀបរាប់ធរណីមាត្រចំណុច បន្ទាត់ និងពហុកោណ
    2. ពន្យល់ពីតូប៉ូឡូស៊ី និងហេតុអ្វីវាសំខាន់
    3. ប្រៀបធៀបទម្រង់ Shapefile និង GeoPackage
    4. កំណត់ និងកែកំហុសធរណីមាត្រ

---

## ៤.១ ធរណីមាត្រមូលដ្ឋាន

*គ្រោង៖* ចំណុច/ពហុចំណុច, បន្ទាត់/ពហុបន្ទាត់, ពហុកោណ/ពហុកោណច្រើន; កំពូល និងថ្នាំង

## ៤.២ តូប៉ូឡូស៊ី

*គ្រោង៖* ភាពជាប់គ្នា (adjacency), ការតភ្ជាប់ (connectivity), ការរុំព័ទ្ធ (containment); គំរូ spaghetti ទល់នឹងគំរូតូប៉ូឡូស៊ី

## ៤.៣ កំហុសធរណីមាត្រទូទៅ

*គ្រោង៖* sliver, gap, dangle, overshoot/undershoot, self-intersection; ឧបករណ៍ Check Validity និង Fix Geometries

## ៤.៤ ទម្រង់ឯកសារវ៉ិចទ័រ

*គ្រោង៖* Shapefile (និងដែនកំណត់៖ ១០ តួឈ្មោះវាល, ២GB, ឯកសារច្រើន); GeoPackage ជាជម្រើសល្អជាង; GeoJSON, KML

## ៤.៥ ការបង្កើត និងកែសម្រួល

*គ្រោង៖* របៀបកែសម្រួល (edit mode), snapping, ការរួមបញ្ចូល/ការបំបែកវត្ថុ

## ៤.៦ ពេលណាគួរប្រើវ៉ិចទ័រ

*គ្រោង៖* ព្រំដែនច្បាស់លាស់, ការវាស់ជាក់លាក់, ទំហំឯកសារតូច

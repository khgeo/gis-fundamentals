# ជំពូក ៥ — គំរូទិន្នន័យរ៉ាស្ទ័រ

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. ពន្យល់រចនាសម្ព័ន្ធក្រឡារ៉ាស្ទ័រ និងគុណភាពបង្ហាញ
    2. បែងចែករ៉ាស្ទ័រប្រភេទតម្លៃ និងប្រភេទថ្នាក់
    3. ពន្យល់ក្រុមរលក (band) និងរូបភាពពហុក្រុមរលក
    4. ជ្រើសរើសទម្រង់ និងវិធីបង្ហាញរ៉ាស្ទ័រសមស្រប

---

## ៥.១ រចនាសម្ព័ន្ធក្រឡា

*គ្រោង៖* ក្រឡាចត្រង្គ; ដើមកំណើត (origin), ទំហំក្រឡា, ចំនួនជួរ/ជួរឈរ; geotransform

## ៥.២ គុណភាពបង្ហាញ

*គ្រោង៖* លំហ (10m Sentinel-2, 30m Landsat), វិសាលគម, ពេលវេលា, វិទ្យុមាត្រ; ការជំនួសគ្នារវាងគុណភាព និងទំហំឯកសារ

## ៥.៣ រ៉ាស្ទ័រជាប់គ្នា ទល់នឹង រ៉ាស្ទ័រថ្នាក់

*គ្រោង៖* DEM/NDVI ទល់នឹង ផែនទីប្រើប្រាស់ដី; ផលប៉ះពាល់ទៅលើវិធី resampling

## ៥.៤ ក្រុមរលក និងរូបភាពផ្កាយរណប

*គ្រោង៖* RGB, NIR, SWIR; ការបញ្ចូលគ្នាពណ៌ពិត/ពណ៌ក្លែង; ណែនាំ NDVI ខ្លីៗ

## ៥.៥ ទម្រង់ឯកសារ និងការបង្ហាប់

*គ្រោង៖* GeoTIFF, Cloud Optimized GeoTIFF, pyramid/overview, NoData

## ៥.៦ ការបង្ហាញ

*គ្រោង៖* ការលាតសន្ធឹងកម្រិតពណ៌ (stretch), តារាងពណ៌, តម្លាភាព

## ៥.៧ វ៉ិចទ័រ ទល់នឹង រ៉ាស្ទ័រ — តារាងសម្រេចចិត្ត

*គ្រោង៖* ការប្រៀបធៀបពេញលេញ; ការបំប្លែងទៅវិញទៅមក

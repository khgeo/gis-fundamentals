# ជំពូក ៤៖ គំរូទិន្នន័យវ៉ិចទ័រ

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. រៀបរាប់ធរណីមាត្រចំណុច បន្ទាត់ និងពហុកោណ

    3. ប្រៀបធៀបទម្រង់ Shapefile និង GeoPackage
    4. កំណត់ និងកែកំហុសធរណីមាត្រ

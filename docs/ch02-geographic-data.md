# ជំពូក ២ — ធម្មជាតិនៃទិន្នន័យភូមិសាស្ត្រ

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. បែងចែកទិន្នន័យលំហ និងទិន្នន័យគុណលក្ខណៈ
    2. ពន្យល់ពីបាតុភូតដាច់ពីគ្នា (discrete) និងបាតុភូតជាប់គ្នា (continuous)
    3. ចាត់ថ្នាក់ទិន្នន័យតាមមាត្រដ្ឋានវាស់ (nominal, ordinal, interval, ratio)
    4. ពន្យល់ពីឥទ្ធិពលនៃមាត្រដ្ឋាន និងលក្ខណៈទូទៅភាវូបនីយកម្ម (generalization)

---

## ២.១ ធាតុផ្សំពីរនៃទិន្នន័យភូមិសាស្ត្រ

*គ្រោង៖* ទីតាំង + គុណលក្ខណៈ + ពេលវេលា; គំនិត 'តារាងមានផែនទី'

## ២.២ បាតុភូតដាច់ពីគ្នា ទល់នឹង បាតុភូតជាប់គ្នា

*គ្រោង៖* ផ្ទះ/ផ្លូវ/ស្រែ ទល់នឹង កម្ពស់/សីតុណ្ហភាព/ទឹកភ្លៀង; ហេតុអ្វីវាកំណត់ជម្រើសវ៉ិចទ័រ/រ៉ាស្ទ័រ

## ២.៣ មាត្រដ្ឋានវាស់ទិន្នន័យ

*គ្រោង៖* តារាងបួនប្រភេទជាមួយឧទាហរណ៍កម្ពុជា; ប្រតិបត្តិការណាអនុញ្ញាតលើប្រភេទណា

## ២.៤ មាត្រដ្ឋានផែនទី និងលក្ខណៈទូទៅភាវូបនីយកម្ម

*គ្រោង៖* 1:10,000 ទល់នឹង 1:1,000,000; ហេតុអ្វីទន្លេមួយអាចជាបន្ទាត់ ឬពហុកោណ

## ២.៥ ច្បាប់ទីមួយនៃភូមិសាស្ត្រ (Tobler)

*គ្រោង៖* គ្រប់របស់ទាក់ទងគ្នា តែរបស់ជិតទាក់ទងខ្លាំងជាង; មូលដ្ឋាននៃការវិភាគលំហ

## ២.៦ ទិន្នន័យតាមពេលវេលា

*គ្រោង៖* ស៊េរីពេលវេលា; ការផ្លាស់ប្ដូរប្រើប្រាស់ដី; ទិន្នន័យ ៤ វិមាត្រ

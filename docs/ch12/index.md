# ជំពូក ១២៖ ការវិភាគផ្ទៃ និងទីសណ្ឋាន

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. ពន្យល់ភាពខុសគ្នារវាង DEM, DSM និង DTM
    2. គណនាជម្រាល ទិសជម្រាល និងស្រមោលភ្នំ
    3. អនុវត្តអាំងទែប៉ូឡាស្យុងដើម្បីបង្កើតផ្ទៃ
    4. ដកស្រង់អាងទឹក និងបណ្ដាញលំហូរពី DEM

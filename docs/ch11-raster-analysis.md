# ជំពូក ១១ — ការវិភាគរ៉ាស្ទ័រ និងពីជគណិតផែនទី

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. អនុវត្តពីជគណិតផែនទីលើរ៉ាស្ទ័រច្រើន
    2. ចាត់ថ្នាក់រ៉ាស្ទ័រឡើងវិញ (reclassify)
    3. គណនាស្ថិតិតាមតំបន់ (zonal statistics)
    4. អនុវត្តការវិភាគសមស្របភាពដោយថ្លឹងទម្ងន់

---

## ១១.១ ពីជគណិតផែនទី

*គ្រោង៖* ប្រតិបត្តិការនព្វន្ធ តក្កវិទ្យា និងលក្ខខណ្ឌលើក្រឡា; Raster Calculator

## ១១.២ សន្ទស្សន៍វិសាលគម

*គ្រោង៖* NDVI = (NIR−RED)/(NIR+RED); NDWI, NDBI; ការបកស្រាយតម្លៃ

## ១១.៣ ការចាត់ថ្នាក់ឡើងវិញ

*គ្រោង៖* ពីតម្លៃជាប់គ្នាទៅថ្នាក់; ការកំណត់ព្រំដែនថ្នាក់ឲ្យសមហេតុផល

## ១១.៤ ការវិភាគជិតខាង (Neighborhood)

*គ្រោង៖* focal statistics; តម្រង mean/majority; ការធ្វើឲ្យរលោង

## ១១.៥ ស្ថិតិតាមតំបន់

*គ្រោង៖* តម្លៃមធ្យម NDVI តាមឃុំ; ការភ្ជាប់រ៉ាស្ទ័រ និងវ៉ិចទ័រ

## ១១.៦ ការវិភាគចម្ងាយ និងដង់ស៊ីតេ

*គ្រោង៖* Proximity/Distance raster; Heatmap (Kernel Density)

## ១១.៧ ការវិភាគសមស្របភាពដោយថ្លឹងទម្ងន់

*គ្រោង៖* ការធ្វើឲ្យតម្លៃស្មើគ្នា (normalize) → ថ្លឹងទម្ងន់ → បូកសរុប; ណែនាំ AHP ខ្លីៗ

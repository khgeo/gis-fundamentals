# ជំពូក ១៥ — គម្រោងអនុវត្តន៍ និងការសង្ខេបវគ្គសិក្សា

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. រៀបចំសំណួរស្រាវជ្រាវដែលអាចឆ្លើយបានដោយ GIS
    2. រចនាលំហូរការងារពេញលេញពីទិន្នន័យដល់ផែនទី
    3. សរសេររបាយការណ៍បច្ចេកទេសខ្លី
    4. បង្ហាញលទ្ធផលដល់ទស្សនិកជនមិនមែនអ្នកបច្ចេកទេស

---

## ១៥.១ ការជ្រើសរើសប្រធានបទ

*គ្រោង៖* លក្ខណៈវិនិច្ឆ័យ៖ ទិន្នន័យមាន, វិសាលភាពសមរម្យ, មានតម្លៃជាក់ស្ដែង

## ១៥.២ ប្រធានបទគំរូសម្រាប់កម្ពុជា

*គ្រោង៖* បញ្ជីយ៉ាងតិច ១០ ប្រធានបទ៖ ការចូលដល់សេវាសុខភាព, ហានិភ័យជំនន់, ការបាត់បង់ព្រៃឈើ, ការរីកធំទីក្រុង, កន្លែងសមស្របសម្រាប់ដំណាំ ។ល។

## ១៥.៣ លំហូរការងារស្តង់ដារ

*គ្រោង៖* សំណួរ → ទិន្នន័យ → រៀបចំ → វិភាគ → ផែនទី → ការបកស្រាយ

## ១៥.៤ រចនាសម្ព័ន្ធរបាយការណ៍

*គ្រោង៖* សេចក្ដីផ្ដើម, ទិន្នន័យ និងវិធីសាស្ត្រ, លទ្ធផល, ការពិភាក្សា, ដែនកំណត់, ឯកសារយោង

## ១៥.៥ បញ្ជីត្រួតពិនិត្យមុនប្រគល់

*គ្រោង៖* CRS ត្រឹមត្រូវ, ធាតុផែនទីគ្រប់, ប្រភពទិន្នន័យបានដកស្រង់, ឯកសារអាចធ្វើម្ដងទៀតបាន

## ១៥.៦ ការសង្ខេបវគ្គសិក្សា

*គ្រោង៖* ការតភ្ជាប់គំនិតពេញ ១៥ សប្ដាហ៍; ផ្លូវសិក្សាបន្ត (ការស្ទង់ពីចម្ងាយ, Python/PyQGIS, ការរៀនម៉ាស៊ីន)

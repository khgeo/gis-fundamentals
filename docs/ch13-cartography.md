# ជំពូក ១៣ — ការធ្វើផែនទី និងការបង្ហាញ

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"

    2. ជ្រើសរើសវិធីចាត់ថ្នាក់ទិន្នន័យ
    3. រៀបចំប្លង់ផែនទីដែលមានធាតុគ្រប់គ្រាន់
    4. វាយតម្លៃ និងរិះគន់ផែនទីដោយវិជ្ជាជីវៈ

## ១៣.១ គោលបំណងផែនទី

*គ្រោង៖* អ្នកអានជានរណា? ផែនទីយោង ទល់នឹង ផែនទីប្រធានបទ

## ១៣.២ អថេរមើលឃើញ

*គ្រោង៖* ទីតាំង, ទំហំ, រូបរាង, តម្លៃពណ៌, សម្លេងពណ៌, វាយនភាព, ទិស; អថេរណាសមនឹងទិន្នន័យប្រភេទណា

## ១៣.៣ ពណ៌

*គ្រោង៖* ក្រម sequential/diverging/qualitative; ColorBrewer; ការគិតគូរអ្នកពិបាកបែងចែកពណ៌; ការបោះពុម្ពសខ្មៅ

## ១៣.៤ ការចាត់ថ្នាក់ទិន្នន័យ

*គ្រោង៖* equal interval, quantile, natural breaks (Jenks), standard deviation; របៀបដែលជម្រើសផ្លាស់ប្ដូរសារផែនទី

## ១៣.៥ ធាតុផែនទី

*គ្រោង៖* ចំណងជើង, តារាងពន្យល់, មាត្រដ្ឋាន, ព្រួញទិសខាងជើង, ប្រភព, CRS, អ្នកផលិត, កាលបរិច្ឆេទ, ផែនទីតូចបន្ថែម

## ១៣.៦ ស្លាកឈ្មោះ និងអក្សរខ្មែរ

*គ្រោង៖* ការដាក់ស្លាក; ការជ្រើសរើសពុម្ពអក្សរខ្មែរ (Khmer OS Battambang, Noto Sans Khmer); បញ្ហាការតម្រៀបជើងអក្សរ

## ១៣.៧ ប្លង់ផែនទីក្នុង QGIS

*គ្រោង៖* Print Layout; atlas; ការនាំចេញជា PDF/PNG សម្រាប់បោះពុម្ព

## ១៣.៨ ផែនទីល្អ និងផែនទីអាក្រក់

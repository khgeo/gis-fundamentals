# ជំពូក ១ — អ្វីទៅជាប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ?

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. ផ្ដល់និយមន័យ GIS និងពន្យល់ពីអ្វីដែលធ្វើឲ្យទិន្នន័យភូមិសាស្ត្រខុសពីទិន្នន័យធម្មតា។
    2. រៀបរាប់សមាសភាគទាំង ៥ នៃ GIS។
    3. បែងចែក GIS ពី CAD, មូលដ្ឋានទិន្នន័យធម្មតា និងការស្ទង់ពីចម្ងាយ។
    4. លើកឧទាហរណ៍ការអនុវត្ត GIS យ៉ាងតិច ៣ ក្នុងបរិបទកម្ពុជា។

---

## ១.១ ចាប់ផ្ដើមពីសំណួរមួយ

ឧបមាថាមន្ត្រីសុខាភិបាលខេត្តមួយសួរថា៖

> *«តើភូមិណាខ្លះនៅឆ្ងាយពីមណ្ឌលសុខភាពលើសពី ១០ គីឡូម៉ែត្រ ហើយមានប្រជាជនលើសពី ៥០០ នាក់?»*

ដើម្បីឆ្លើយសំណួរនេះ យើងត្រូវការព័ត៌មានពីរប្រភេទដាច់ដោយឡែក៖

- **ព័ត៌មានថា វត្ថុនោះមានលក្ខណៈអ្វី** — ឈ្មោះភូមិ, ចំនួនប្រជាជន, ឈ្មោះមណ្ឌលសុខភាព។ ព័ត៌មាននេះអាចដាក់ក្នុងតារាង Excel ធម្មតាបាន។
- **ព័ត៌មានថា វត្ថុនោះនៅទីណា** — ទីតាំងភូមិនីមួយៗ និងទីតាំងមណ្ឌលសុខភាពនីមួយៗនៅលើផែនដី។

តារាង Excel តែឯងមិនអាចឆ្លើយសំណួរនេះបានទេ ព្រោះវាមិនដឹងថា "ឆ្ងាយ ១០ គីឡូម៉ែត្រ" មានន័យដូចម្ដេចឡើយ។ ផែនទីក្រដាសតែឯងក៏មិនអាចឆ្លើយបានដែរ ព្រោះយើងមិនអាចឲ្យផែនទីក្រដាសរាប់ប្រជាជនបាន។

**GIS គឺជាឧបករណ៍ដែលភ្ជាប់ព័ត៌មានទាំងពីរនេះចូលគ្នា** រួចអនុញ្ញាតឲ្យយើងសួរសំណួរដែលពាក់ព័ន្ធនឹងទាំង *អ្វី* និង *ទីណា* ក្នុងពេលតែមួយ។

## ១.២ និយមន័យ

> **ប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ (Geographic Information System — GIS)** គឺជាប្រព័ន្ធសម្រាប់ **ប្រមូល រក្សាទុក គ្រប់គ្រង វិភាគ និងបង្ហាញ** ទិន្នន័យដែលមានទីតាំងលើផ្ទៃផែនដី។

ចំណុចសំខាន់ក្នុងនិយមន័យនេះគឺពាក្យ **វិភាគ**។ កម្មវិធីជាច្រើនអាចបង្ហាញផែនទីបាន (ដូចជា Google Maps) ប៉ុន្តែ GIS ពិតប្រាកដត្រូវតែអាច *គណនា* លើទិន្នន័យលំហ — រកចម្ងាយ, រកតំបន់ត្រួតគ្នា, បូកបញ្ចូលតម្លៃតាមតំបន់ ជាដើម។

### GIS ទល់នឹង GIScience

- **GIS** = ប្រព័ន្ធ ឬឧបករណ៍ (កម្មវិធី + ទិន្នន័យ + នីតិវិធី)។
- **GIScience** (វិទ្យាសាស្ត្រព័ត៌មានភូមិសាស្ត្រ) = វិស័យសិក្សាស្រាវជ្រាវអំពីទ្រឹស្ដីនៅពីក្រោយប្រព័ន្ធនោះ — របៀបតំណាងលំហ, ភាពមិនប្រាកដប្រជា, ការយល់ឃើញអំពីលំហ។

មុខវិជ្ជានេះផ្ដោតលើ **GIS** ជាចម្បង ប៉ុន្តែយើងនឹងប៉ះពាល់គោលគំនិត GIScience នៅពេលចាំបាច់ (ជាពិសេសក្នុងជំពូក ៣ និង ៨)។

## ១.៣ សមាសភាគទាំង ៥ នៃ GIS

GIS មិនមែនគ្រាន់តែជាកម្មវិធីទេ។ វាជាប្រព័ន្ធពេញលេញដែលមានសមាសភាគ ៥៖

| សមាសភាគ | ខ្លឹមសារ | ឧទាហរណ៍ |
|---|---|---|
| **១. ផ្នែករឹង** (Hardware) | ឧបករណ៍រូបវន្ត | កុំព្យូទ័រ, ម៉ាស៊ីនបម្រើ, ឧបករណ៍ GNSS, ដ្រូន, ម៉ាស៊ីនបោះពុម្ពផែនទី |
| **២. ផ្នែកទន់** (Software) | កម្មវិធីដំណើរការ | QGIS, ArcGIS, GRASS, PostGIS, Google Earth Engine |
| **៣. ទិន្នន័យ** (Data) | ចំណែកថ្លៃបំផុត | ស្រទាប់ព្រំដែន, រូបភាពផ្កាយរណប, ស្ថិតិប្រជាជន |
| **៤. មនុស្ស** (People) | អ្នកប្រើ និងអ្នកបង្កើត | អ្នកវិភាគ GIS, អ្នកបច្ចេកទេស, អ្នកសម្រេចចិត្ត |
| **៥. នីតិវិធី** (Methods) | ច្បាប់ និងលំហូរការងារ | ស្តង់ដារគុណភាព, ពិធីការប្រមូលទិន្នន័យ, ទម្រង់ផែនទីស្តង់ដារ |

!!! warning "កំហុសទូទៅ"
    អ្នកចាប់ផ្ដើមថ្មីច្រើនតែគិតថា GIS = កម្មវិធី។ តាមពិត **ទិន្នន័យ** ជាធម្មតាចំណាយ ៦០–៨០% នៃថវិកាគម្រោង GIS មួយ ហើយ **មនុស្ស** ជាកត្តាកំណត់ថាគម្រោងជោគជ័យឬបរាជ័យ។ កម្មវិធី QGIS ឥតគិតថ្លៃ — ប៉ុន្តែទិន្នន័យល្អ និងមនុស្សចេះដឹង មិនឥតគិតថ្លៃទេ។

## ១.៤ សំណួរ ៥ ប្រភេទដែល GIS ឆ្លើយបាន

វិធីងាយស្រួលដើម្បីយល់ពីសមត្ថភាព GIS គឺមើលតាមប្រភេទសំណួរ៖

1. **ទីតាំង** — *មានអ្វីនៅទីនេះ?*
   ឧ. ភូមិណាស្ថិតក្នុងចម្ងាយ ២ គីឡូម៉ែត្រពីដងទន្លេមេគង្គ?

2. **លក្ខខណ្ឌ** — *តើកន្លែងណាដែលត្រូវនឹងលក្ខខណ្ឌរបស់ខ្ញុំ?*
   ឧ. រកដីមានជម្រាលតិចជាង ៥% មានទឹកជិត និងនៅក្រៅតំបន់ការពារ។

3. **និន្នាការ** — *តើមានអ្វីផ្លាស់ប្ដូរតាំងពីពេលនោះមក?*
   ឧ. ព្រៃឈើនៅខេត្តមណ្ឌលគិរីបាត់បង់ប៉ុន្មានហិកតាចន្លោះឆ្នាំ ២០១៥ ដល់ ២០២៥?

4. **លំនាំ** — *តើមានលំនាំលំហអ្វី?*
   ឧ. តើគ្រោះថ្នាក់ចរាចរណ៍ក្នុងរាជធានីភ្នំពេញប្រមូលផ្ដុំនៅចំណុចណាខ្លះ?

5. **គំរូ** — *បើ...នោះនឹងយ៉ាងណា?*
   ឧ. បើទឹកទន្លេឡើងខ្ពស់ ២ ម៉ែត្រ តើផ្ទះប៉ុន្មានខ្នងនឹងលិចទឹក?

សំណួរប្រភេទទី ១ និង ២ គឺជាមូលដ្ឋាន ហើយយើងនឹងរៀនក្នុងជំពូក ៩ និង ១០។ ប្រភេទទី ៥ ជាកម្រិតខ្ពស់ ហើយត្រូវការជំនាញបន្ថែម។

## ១.៥ GIS ខុសពីអ្វីខ្លះ?

| ប្រព័ន្ធ | មានទីតាំងភូមិសាស្ត្រ? | មានគុណលក្ខណៈ? | វិភាគលំហបាន? |
|---|:---:|:---:|:---:|
| តារាង Excel | ✗ | ✓ | ✗ |
| មូលដ្ឋានទិន្នន័យធម្មតា (DBMS) | ✗ | ✓ | ✗ |
| CAD (AutoCAD) | ផ្នែក* | ✗ | ✗ |
| ការស្ទង់ពីចម្ងាយ (Remote Sensing) | ✓ | ផ្នែក | ផ្នែក |
| **GIS** | **✓** | **✓** | **✓** |

\* CAD ប្រើកូអរដោនេក្នុងស្រុក (local coordinates) សម្រាប់គំនូរវិស្វកម្ម មិនមែនកូអរដោនេលើផែនដីពិតទេ លុះត្រាតែមានការកំណត់បន្ថែម។

### ទំនាក់ទំនងជាមួយការស្ទង់ពីចម្ងាយ

**ការស្ទង់ពីចម្ងាយ (Remote Sensing)** គឺជាវិធីសាស្ត្រ *ប្រមូល* ទិន្នន័យពីផ្កាយរណបឬដ្រូន។ **GIS** គឺជាកន្លែង *វិភាគ* ទិន្នន័យនោះរួមជាមួយទិន្នន័យផ្សេងទៀត។ ទាំងពីរទាក់ទងគ្នាយ៉ាងជិតស្និទ្ធ ប៉ុន្តែមិនដូចគ្នាទេ។ ក្នុងជំពូក ៥ និង ៧ យើងនឹងប្រើរូបភាពផ្កាយរណបជាទិន្នន័យចូលក្នុង GIS។

| ២០១០–បច្ចុប្បន្ន | GIS លើពពក (Google Earth Engine), ទិន្នន័យធំ, បញ្ញាសិប្បនិម្មិត, និងឌីជីថលភ្លោះ (Digital Twin)។ |

## ១.៧ ការអនុវត្ត GIS នៅកម្ពុជា

GIS មិនមែនជារឿងទ្រឹស្ដីសម្រាប់កម្ពុជាទេ។ ឧទាហរណ៍ជាក់ស្ដែង៖

**ក. គ្រប់គ្រងគ្រោះមហន្តរាយ**
ការគូសផែនទីជំនន់ទឹកភ្លៀងតាមដងទន្លេមេគង្គ និងទន្លេសាប ដោយប្រើរូបភាពផ្កាយរណប SAR (Sentinel-1) ដែលអាចមើលទម្លុះពពកបាន។ លទ្ធផលជួយ NCDM កំណត់តំបន់ជម្លៀស។

**ខ. កសិកម្ម**
តាមដានការលូតលាស់ដំណាំស្រូវតាមខេត្តដោយប្រើសន្ទស្សន៍បន្លែ (NDVI) ពី Sentinel-2 ដើម្បីប៉ាន់ស្មានទិន្នផល និងព្រមានពីគ្រោះរាំងស្ងួត។

**គ. ការគ្រប់គ្រងព្រៃឈើ**
តាមដានការបាត់បង់ព្រៃឈើប្រចាំឆ្នាំ (ឧ. ទិន្នន័យ Global Forest Change) ក្នុងតំបន់ការពារដូចជាភ្នំគូលែន និងមណ្ឌលគិរី។

**ឃ. ប្លង់ទីក្រុង**
រាជធានីភ្នំពេញប្រើ GIS សម្រាប់ផែនទីប្រើប្រាស់ដី (LULC), បណ្ដាញលូ, និងការវិភាគកំដៅទីក្រុង (Urban Heat Island)។

**ង. បេតិកភណ្ឌវប្បធម៌**
អាជ្ញាធរអប្សរាប្រើ GIS និង LiDAR សម្រាប់គូសផែនទីប្រាសាទ និងប្រព័ន្ធទឹកបុរាណនៅតំបន់អង្គរ។

**ច. សុខាភិបាល**
ការវិភាគចម្ងាយធ្វើដំណើរទៅមណ្ឌលសុខភាព ដើម្បីកំណត់តំបន់ដែលខ្វះសេវា។

## ១.៨ ហេតុអ្វីប្រើ QGIS ក្នុងមុខវិជ្ជានេះ?

- **ឥតគិតថ្លៃ និងបើកចំហ** — និស្សិតអាចដំឡើងនៅផ្ទះ និងបន្តប្រើក្រោយបញ្ចប់ការសិក្សាដោយគ្មានអាជ្ញាបណ្ណ។
- **ដំណើរការគ្រប់ប្រព័ន្ធ** — Windows, macOS, Linux។
- **អានបានគ្រប់ទម្រង់** — Shapefile, GeoPackage, GeoTIFF, PostGIS, សេវាវេប។
- **មានកម្មវិធីបន្ថែម (plugin) ច្រើន** — រួមទាំងការភ្ជាប់ទៅ Google Earth Engine។
- **ប្រើជាក់ស្ដែងក្នុងស្ថាប័ននៅកម្ពុជា** — ក្រសួង, អង្គការ NGO, និងក្រុមហ៊ុនប្រឹក្សា។

## សង្ខេបជំពូក

- GIS ភ្ជាប់ព័ត៌មាន **"អ្វី"** (គុណលក្ខណៈ) ជាមួយព័ត៌មាន **"ទីណា"** (ទីតាំង)។
- GIS មានសមាសភាគ ៥៖ ផ្នែករឹង, ផ្នែកទន់, ទិន្នន័យ, មនុស្ស, នីតិវិធី។
- អ្វីដែលបែងចែក GIS ពីកម្មវិធីផែនទីធម្មតាគឺ **សមត្ថភាពវិភាគលំហ**។
- GIS ឆ្លើយសំណួរ ៥ ប្រភេទ៖ ទីតាំង, លក្ខខណ្ឌ, និន្នាការ, លំនាំ, និងគំរូ។
- នៅកម្ពុជា GIS ត្រូវបានប្រើក្នុងគ្រោះមហន្តរាយ, កសិកម្ម, ព្រៃឈើ, ប្លង់ទីក្រុង, បេតិកភណ្ឌ និងសុខាភិបាល។

## ពាក្យគន្លឹះ

ប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ (GIS) · ទិន្នន័យលំហ (spatial data) · ទិន្នន័យគុណលក្ខណៈ (attribute data) · ស្រទាប់ (layer) · ការវិភាគលំហ (spatial analysis) · ការស្ទង់ពីចម្ងាយ (remote sensing)

# មេរៀន ១.២៖ សមាសភាគទាំង ៥ និងសំណួរដែល GIS ឆ្លើយបាន

## ១.២.១ សមាសភាគទាំង ៥ នៃ GIS

GIS មិនមែនគ្រាន់តែជាកម្មវិធីទេ។ វាជាប្រព័ន្ធពេញលេញដែលមានសមាសភាគ ៥។

<figcaption>រូបភាព ១.៣៖ សមាសភាគទាំង ៥។ ពណ៌ដិតបង្ហាញសមាសភាគដែលចំណាយច្រើនបំផុត។</figcaption>

| សមាសភាគ | ខ្លឹមសារ | ឧទាហរណ៍ |
|---|---|---|
| **១. ផ្នែករឹង** (Hardware) | ឧបករណ៍រូបវន្ត | កុំព្យូទ័រ, ម៉ាស៊ីនបម្រើ, ឧបករណ៍ GNSS, ដ្រូន, ម៉ាស៊ីនបោះពុម្ពផែនទី |
| **២. ផ្នែកទន់** (Software) | កម្មវិធីដំណើរការ | QGIS, ArcGIS, GRASS, PostGIS, Google Earth Engine |
| **៣. ទិន្នន័យ** (Data) | ចំណែកថ្លៃបំផុត | ស្រទាប់ព្រំដែន, រូបភាពផ្កាយរណប, ស្ថិតិប្រជាជន |
| **៤. មនុស្ស** (People) | អ្នកប្រើ និងអ្នកបង្កើត | អ្នកវិភាគ GIS, អ្នកបច្ចេកទេស, អ្នកសម្រេចចិត្ត |
| **៥. នីតិវិធី** (Methods) | ច្បាប់ និងលំហូរការងារ | ស្តង់ដារគុណភាព, ពិធីការប្រមូលទិន្នន័យ, ទម្រង់ផែនទីស្តង់ដារ |

!!! warning "កំហុសទូទៅ"
    អ្នកចាប់ផ្ដើមថ្មីច្រើនតែគិតថា GIS ស្មើនឹងកម្មវិធី។ តាមពិត **ទិន្នន័យ** ជាធម្មតាចំណាយ ៦០ ទៅ ៨០ ភាគរយនៃថវិកាគម្រោង GIS មួយ ហើយ **មនុស្ស** ជាកត្តាកំណត់ថាគម្រោងជោគជ័យឬបរាជ័យ។ កម្មវិធី QGIS ឥតគិតថ្លៃ ប៉ុន្តែទិន្នន័យល្អ និងមនុស្សចេះដឹង មិនឥតគិតថ្លៃទេ។

## ១.២.២ សំណួរ ៥ ប្រភេទដែល GIS ឆ្លើយបាន

វិធីងាយស្រួលដើម្បីយល់ពីសមត្ថភាព GIS គឺមើលតាមប្រភេទសំណួរ។

1. **ទីតាំង៖** *មានអ្វីនៅទីនេះ?*
   ឧទាហរណ៍៖ ភូមិណាស្ថិតក្នុងចម្ងាយ ២ គីឡូម៉ែត្រពីដងទន្លេមេគង្គ?

2. **លក្ខខណ្ឌ៖** *តើកន្លែងណាដែលត្រូវនឹងលក្ខខណ្ឌរបស់ខ្ញុំ?*
   ឧទាហរណ៍៖ រកដីមានជម្រាលតិចជាង ៥ ភាគរយ មានទឹកជិត និងនៅក្រៅតំបន់ការពារ។

3. **និន្នាការ៖** *តើមានអ្វីផ្លាស់ប្ដូរតាំងពីពេលនោះមក?*
   ឧទាហរណ៍៖ ព្រៃឈើនៅខេត្តមណ្ឌលគិរីបាត់បង់ប៉ុន្មានហិកតាចន្លោះឆ្នាំ ២០១៥ ដល់ ២០២៥?

4. **លំនាំ៖** *តើមានលំនាំលំហអ្វី?*
   ឧទាហរណ៍៖ តើគ្រោះថ្នាក់ចរាចរណ៍ក្នុងរាជធានីភ្នំពេញប្រមូលផ្ដុំនៅចំណុចណាខ្លះ?

5. **គំរូ៖** *បើ...នោះនឹងយ៉ាងណា?*
   ឧទាហរណ៍៖ បើទឹកទន្លេឡើងខ្ពស់ ២ ម៉ែត្រ តើផ្ទះប៉ុន្មានខ្នងនឹងលិចទឹក?

សំណួរប្រភេទទី ១ និងទី ២ គឺជាមូលដ្ឋាន ហើយយើងនឹងរៀនក្នុងជំពូក ៩ និង ១០។ ប្រភេទទី ៥ ជាកម្រិតខ្ពស់ ហើយត្រូវការជំនាញបន្ថែម។

## សំណួរពិនិត្យ

1. រៀបរាប់សមាសភាគទាំង ៥ នៃ GIS ហើយពន្យល់ថាមួយណាថ្លៃបំផុត និងហេតុអ្វី។
2. សរសេរសំណួរមួយសម្រាប់ប្រភេទនីមួយៗក្នុងចំណោមសំណួរ ៥ ប្រភេទ ដោយផ្អែកលើតំបន់ដែលអ្នករស់នៅ។
3. ហេតុអ្វីសមាសភាគ «នីតិវិធី» ត្រូវបានគេភ្លេចញឹកញាប់បំផុត?

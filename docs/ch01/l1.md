# មេរៀន ១.១៖ ទីតាំង គុណលក្ខណៈ និងស្រទាប់

## ១.១.១ ចាប់ផ្ដើមពីសំណួរមួយ

ឧបមាថាមន្ត្រីសុខាភិបាលខេត្តមួយសួរថា៖

> *«តើភូមិណាខ្លះនៅឆ្ងាយពីមណ្ឌលសុខភាពលើសពី ១០ គីឡូម៉ែត្រ ហើយមានប្រជាជនលើសពី ៥០០ នាក់?»*

ដើម្បីឆ្លើយសំណួរនេះ យើងត្រូវការព័ត៌មានពីរប្រភេទដាច់ដោយឡែក។

<figcaption>រូបភាព ១.១៖ GIS ភ្ជាប់ទីតាំងលើផែនទីជាមួយជួរដេកក្នុងតារាង។</figcaption>
</figure>

- **ព័ត៌មានថាវត្ថុនោះមានលក្ខណៈអ្វី** គឺឈ្មោះភូមិ, ចំនួនប្រជាជន, ឈ្មោះមណ្ឌលសុខភាព។ ព័ត៌មាននេះអាចដាក់ក្នុងតារាង Excel ធម្មតាបាន។
- **ព័ត៌មានថាវត្ថុនោះនៅទីណា** គឺទីតាំងភូមិនីមួយៗ និងទីតាំងមណ្ឌលសុខភាពនីមួយៗនៅលើផែនដី។

តារាង Excel តែឯងមិនអាចឆ្លើយសំណួរនេះបានទេ ព្រោះវាមិនដឹងថា «ឆ្ងាយ ១០ គីឡូម៉ែត្រ» មានន័យដូចម្ដេចឡើយ។ ផែនទីក្រដាសតែឯងក៏មិនអាចឆ្លើយបានដែរ ព្រោះយើងមិនអាចឲ្យផែនទីក្រដាសរាប់ប្រជាជនបាន។

**GIS គឺជាឧបករណ៍ដែលភ្ជាប់ព័ត៌មានទាំងពីរនេះចូលគ្នា** រួចអនុញ្ញាតឲ្យយើងសួរសំណួរដែលពាក់ព័ន្ធនឹងទាំង *អ្វី* និង *ទីណា* ក្នុងពេលតែមួយ។

## ១.១.២ និយមន័យ

> **ប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ (Geographic Information System, GIS)** គឺជាប្រព័ន្ធសម្រាប់ **ប្រមូល រក្សាទុក គ្រប់គ្រង វិភាគ និងបង្ហាញ** ទិន្នន័យដែលមានទីតាំងលើផ្ទៃផែនដី។

ចំណុចសំខាន់ក្នុងនិយមន័យនេះគឺពាក្យ **វិភាគ**។ កម្មវិធីជាច្រើនអាចបង្ហាញផែនទីបាន ដូចជា Google Maps ប៉ុន្តែ GIS ពិតប្រាកដត្រូវតែអាច *គណនា* លើទិន្នន័យលំហ ដូចជារកចម្ងាយ, រកតំបន់ត្រួតគ្នា, ឬបូកបញ្ចូលតម្លៃតាមតំបន់។

### GIS ទល់នឹង GIScience

- **GIS** គឺជាប្រព័ន្ធ ឬឧបករណ៍ (កម្មវិធី + ទិន្នន័យ + នីតិវិធី)។
- **GIScience** (វិទ្យាសាស្ត្រព័ត៌មានភូមិសាស្ត្រ) គឺជាវិស័យសិក្សាស្រាវជ្រាវអំពីទ្រឹស្ដីនៅពីក្រោយប្រព័ន្ធនោះ ដូចជារបៀបតំណាងលំហ, ភាពមិនប្រាកដប្រជា, និងការយល់ឃើញអំពីលំហ។

មុខវិជ្ជានេះផ្ដោតលើ **GIS** ជាចម្បង ប៉ុន្តែយើងនឹងប៉ះពាល់គោលគំនិត GIScience នៅពេលចាំបាច់ ជាពិសេសក្នុងជំពូក ៣ និង ៨។

## ១.១.៣ គំនិតស្រទាប់ (Layer)

GIS រៀបចំពិភពពិតជា **ស្រទាប់ (layer)** ដាច់ៗពីគ្នា។ ស្រទាប់នីមួយៗផ្ទុកបាតុភូតតែមួយប្រភេទ ហើយរក្សាទុកជាឯកសារដាច់ដោយឡែក។ ព្រោះស្រទាប់ទាំងអស់ចែករំលែកប្រព័ន្ធកូអរដោនេតែមួយ យើងអាចដាក់វាត្រួតលើគ្នា ហើយវិភាគទំនាក់ទំនងរវាងស្រទាប់បាន។

## សំណួរពិនិត្យ

1. ពន្យល់ដោយប្រើឧទាហរណ៍ផ្ទាល់ខ្លួន ថាហេតុអ្វីតារាង Excel មិនអាចជំនួស GIS បាន។
2. តើអ្វីជាភាពខុសគ្នារវាង GIS និង GIScience?
3. ចូររាយឈ្មោះស្រទាប់យ៉ាងតិច ៤ ដែលអ្នកត្រូវការ ដើម្បីធ្វើផែនទីហានិភ័យជំនន់សម្រាប់ស្រុករបស់អ្នក។

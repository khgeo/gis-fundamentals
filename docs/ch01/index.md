# ជំពូក ១៖ អ្វីទៅជាប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ?

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. ផ្ដល់និយមន័យ GIS និងពន្យល់ពីអ្វីដែលធ្វើឲ្យទិន្នន័យភូមិសាស្ត្រខុសពីទិន្នន័យធម្មតា។
    2. រៀបរាប់សមាសភាគទាំង ៥ នៃ GIS។
    3. បែងចែក GIS ពី CAD, មូលទិន្នន័យធម្មតា និងការយកព័ត៌មានពីចម្ងាយ។
    4. លើកឧទាហរណ៍ការអនុវត្ត GIS យ៉ាងតិច ៣ ក្នុងបរិបទកម្ពុជា។

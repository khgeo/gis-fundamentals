# ជំពូក ៧៖ ប្រភព និងការប្រមូលទិន្នន័យនៅកម្ពុជា

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. រៀបរាប់ប្រភពទិន្នន័យភូមិសាស្ត្រសំខាន់ៗសម្រាប់កម្ពុជា
    2. វាយតម្លៃភាពសមស្រប និងអាជ្ញាបណ្ណទិន្នន័យ
    3. ប្រមូលទិន្នន័យវាលដោយប្រើ GNSS
    4. ទាញយកទិន្នន័យពី OpenStreetMap និងបណ្ណសារផ្កាយរណបបើកចំហ

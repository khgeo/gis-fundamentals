# វាក្យសព្ទបច្ចេកទេស (Glossary)

តារាងខាងក្រោមជាវាក្យសព្ទស្តង់ដារដែលប្រើពេញក្នុងសៀវភៅនេះ។ ពាក្យបច្ចេកទេសនីមួយៗត្រូវបានសរសេរជា **ខ្មែរ (English)** នៅពេលប្រើលើកដំបូងក្នុងជំពូកនីមួយៗ រួចប្រើតែពាក្យខ្មែរនៅពេលក្រោយ។

> **ចំណាំសម្រាប់គ្រូបង្រៀន៖** វាក្យសព្ទ GIS ជាភាសាខ្មែរមិនទាន់មានស្តង់ដារជាតិពេញលេញនៅឡើយទេ។ ពាក្យខ្លះខាងក្រោមជាពាក្យប្រើប្រាស់ទូទៅ ពាក្យខ្លះទៀតជាពាក្យដែលសៀវភៅនេះជ្រើសរើស។ ជួរឈរ **ស្ថានភាព** បង្ហាញកម្រិតនៃការទទួលយក។ បើសាកលវិទ្យាល័យរបស់អ្នកប្រើពាក្យផ្សេង សូមកែក្នុងឯកសារនេះមុនគេ ព្រោះជំពូកទាំងអស់យោងតាមតារាងនេះ។

ស្ថានភាព៖ ✅ = ប្រើទូទៅ · ⚠️ = មានច្រើនបែប · 🔤 = ប្រតិលេខសូរស័ព្ទ (transliteration)

## ការប្រើប្រាស់ក្នុងថ្នាក់

១. និស្សិតគួរចេះ **ទាំងពាក្យខ្មែរ និងពាក្យអង់គ្លេស** ព្រោះកម្មវិធី QGIS និងឯកសារបច្ចេកទេសភាគច្រើនជាភាសាអង់គ្លេស។
២. ក្នុងការប្រឡង សំណួរប្រើពាក្យខ្មែរ ហើយដាក់ពាក្យអង់គ្លេសក្នុងវង់ក្រចក។
៣. ឈ្មោះឧបករណ៍ក្នុង QGIS (ឧ. `Buffer`, `Clip`, `Field Calculator`) **មិនបកប្រែទេ**, សរសេរជាអង់គ្លេសដើម្បីឲ្យនិស្សិតរកឃើញក្នុងកម្មវិធី។

# ជំពូក ៦ — គុណលក្ខណៈ និងមូលដ្ឋានទិន្នន័យ

!!! warning "ស្ថានភាព៖ គ្រោងជំពូក"
    ជំពូកនេះមានតែគ្រោងនៅឡើយ។ ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [ជំពូក ១](ch01-introduction.md) សម្រាប់ទម្រង់ពេញលេញ។

!!! abstract "គោលដៅជំពូក"
    នៅចុងជំពូកនេះ និស្សិតអាច៖

    1. រចនាតារាងគុណលក្ខណៈជាមួយប្រភេទវាលត្រឹមត្រូវ
    2. ភ្ជាប់តារាងក្រៅ (join) ជាមួយស្រទាប់លំហ
    3. ប្រើ Field Calculator ដើម្បីបង្កើតវាលថ្មី
    4. ពន្យល់គោលការណ៍មូលដ្ឋានទិន្នន័យទំនាក់ទំនង និង PostGIS

---

## ៦.១ រចនាសម្ព័ន្ធតារាងគុណលក្ខណៈ

*គ្រោង៖* ជួរដេក = វត្ថុ, ជួរឈរ = វាល; សោចម្បង (primary key)

## ៦.២ ប្រភេទវាល

*គ្រោង៖* integer, real, string, date, boolean; កំហុសទូទៅ (លេខទុកជាអក្សរ)

## ៦.៣ ការភ្ជាប់តារាង (Join)

*គ្រោង៖* attribute join តាមវាលរួម; one-to-one ទល់នឹង one-to-many; ការភ្ជាប់ស្ថិតិ NIS ជាមួយព្រំដែនឃុំ

## ៦.៤ Field Calculator

*គ្រោង៖* កន្សោមមូលដ្ឋាន; $area, $length, concat, CASE WHEN; ចំណាំអំពី CRS ពេលគណនាផ្ទៃក្រឡា

## ៦.៥ មូលដ្ឋានទិន្នន័យទំនាក់ទំនង

*គ្រោង៖* តារាងច្រើនភ្ជាប់គ្នា; ការធ្វើឲ្យធម្មតា (normalization) ខ្លីៗ

## ៦.៦ ណែនាំ PostGIS

*គ្រោង៖* ហេតុអ្វីប្រើមូលដ្ឋានទិន្នន័យលំហសម្រាប់ទិន្នន័យធំ និងអ្នកប្រើច្រើននាក់

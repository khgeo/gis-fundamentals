# សៀវភៅទី២៖ មូលដ្ឋានគ្រឹះនៃប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ

### សម្រាប់វគ្គសិក្សា ១ ឆមាស · ៤៥ ម៉ោង · ១៥ មេរៀន · ១៥ លំហាត់ QGIS · ជាភាសាខ្មែរ

---

សៀវភៅនេះជាឯកសារបង្រៀនពេញលេញសម្រាប់មុខវិជ្ជា **មូលដ្ឋានគ្រឹះនៃ GIS** កម្រិតបរិញ្ញាបត្រ ឆ្នាំទី២ ឆមាសទី២ ដេប៉ាតឺម៉ង់ភូមិវិទ្យា និងរៀបចំដែនដី។ វាមាន **១៥ មេរៀនទ្រឹស្ដី** (៣ ម៉ោងក្នុងមួយមេរៀន) និង **សៀវភៅអនុវត្ត ១៥ លំហាត់** លើ **QGIS** ដែលប្រើទិន្នន័យពិតរបស់កម្ពុជា។ មេរៀន និងលំហាត់មានផែនទីអន្តរកម្ម ពិសោធន៍ និងប្រអប់ពិនិត្យខ្លួនឯង។

ខ្លឹមសារទាំងអស់ត្រូវបានសរសេរក្នុងបរិបទ **កម្ពុជា**។

## ស៊េរីសៀវភៅទាំង ៤

សៀវភៅនេះជាផ្នែកមួយនៃស៊េរីសម្រាប់ឆ្នាំទី២ និងទី៣។

| សៀវភៅ | ចំណងជើង | ឆ្នាំ/ឆមាស |
|---|---|---|
| ទី១ | [ផែនទីវិទ្យា](https://khgeo.github.io/cartography/) | ឆ្នាំទី២ ឆមាសទី១ |
| **ទី២** | **មូលដ្ឋានគ្រឹះនៃ GIS** ← សៀវភៅនេះ | ឆ្នាំទី២ ឆមាសទី២ |
| ទី៣ | [មូលដ្ឋានគ្រឹះនៃការយកព័ត៌មានពីចម្ងាយ](https://khgeo.github.io/remote-sensing/) | ឆ្នាំទី៣ ឆមាសទី១ |
| ទី៤ | [អនុវត្តន៍ GIS និងការយកព័ត៌មានពីចម្ងាយ](https://khgeo.github.io/applied-gis-rs/) | ឆ្នាំទី៣ ឆមាសទី២ |

!!! abstract "អ្វីដែលសៀវភៅនេះមិនបង្រៀន"
    **មាត្រដ្ឋាន ចំណោល ការរចនាផែនទី និងការចាត់ថ្នាក់ដើម្បីបង្ហាញ** ជាខ្លឹមសារសៀវភៅទី១។ សៀវភៅនេះប្រើវាជាឧបករណ៍ ហើយតម្រូវឲ្យនិស្សិតធ្វើផែនទីតាមស្តង់ដារសៀវភៅទី១ ប៉ុន្តែមិនបង្រៀនទ្រឹស្ដីឡើងវិញទេ។

    **រូបវិទ្យាវិសាលគម ឧបករណ៍ចាប់សញ្ញា និងការចាត់ថ្នាក់រូបភាព** ជាខ្លឹមសារសៀវភៅទី៣។ សៀវភៅនេះប្រើ NDVI ជាឧទាហរណ៍ពីជគណិតផែនទីតែប៉ុណ្ណោះ។

## អានដោយគ្មានអ៊ីនធឺណិត

<div class="offline-save"></div>

- **ទូរសព្ទ ឬកុំព្យូទ័រផ្ទាល់ខ្លួន**៖ ចុចប៊ូតុងខាងលើម្ដង ពេលមាន Wi-Fi។ ក្រោយមក បើកតំណ [khgeo.github.io/gis-fundamentals](https://khgeo.github.io/gis-fundamentals/) ដដែល ទោះគ្មានអ៊ីនធឺណិតក៏បាន។ មេរៀន លំហាត់ **ស្លាយបង្រៀន** និងពិសោធន៍ ត្រូវបានរក្សាទុកទាំងអស់។ លើទូរសព្ទ ប្រើ «Add to Home screen» ដើម្បីបើកដូចកម្មវិធី។
- **កុំព្យូទ័របន្ទប់ពិសោធន៍ ឬគ្មានអ៊ីនធឺណិតសោះ**៖ ទាញយក [កំណែ offline (ZIP)](https://khgeo.github.io/gis-fundamentals/downloads/gis-fundamentals-offline.zip) ចម្លងតាម USB ពន្លា (Extract) ហើយបើក `START_HERE.html` ក្នុង Chrome, Edge ឬ Firefox។ មិនចាំបាច់ដំឡើងអ្វីទេ។
- ស្លាយបើកជារបៀបបញ្ចាំង (slide show) ពេញអេក្រង់បានទាំងពីររបៀប។ ផែនទីផ្ទៃក្រោយ OpenStreetMap ក្នុងលំហាត់ តំណខាងក្រៅ និង Earth Engine នៅតែត្រូវការអ៊ីនធឺណិត។

# លំហាត់ទី១០៖ តើភូមិណាខ្លះនៅឆ្ងាយពីមណ្ឌលសុខភាព?

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១០៖ បាហ្វ័រ និងការវិភាគភាពជិត](../lessons/lesson-10.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១០០ នាទី

## ស្ថានភាព

មន្ទីរសុខាភិបាលខេត្តកំពង់ឆ្នាំងចង់ដឹងថា ភូមិណាខ្លះនៅឆ្ងាយពីមណ្ឌលសុខភាពជាង **៥ គីឡូម៉ែត្រ** និងមានប្រជាជនប៉ុន្មាននាក់រស់នៅក្នុងភូមិទាំងនោះ។ លទ្ធផលនេះនឹងប្រើសម្រាប់ពិភាក្សាទីតាំងប៉ុស្តិ៍សុខភាពថ្មី។

## គោលបំណង

- បង្កើតបាហ្វ័រជុំវិញវត្ថុចំណុច និងរំលាយព្រំដែនបាហ្វ័រ។
- ជ្រើសរើសវត្ថុតាមទីតាំងដោយប្រើទំនាក់ទំនងលំហ។
- គណនាចម្ងាយពីវត្ថុនីមួយៗទៅវត្ថុជិតបំផុត ហើយចាត់ថ្នាក់ចម្ងាយ។
- ពន្យល់ឥទ្ធិពលគែម (edge effect) និងដែនកំណត់នៃចម្ងាយបន្ទាត់ត្រង់។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។

| ស្រទាប់ | ថត | ខ្លឹមសារ |
|---|---|---|
| `Kh_Province_Boundary` | `Admin/` | ព្រំខេត្ត ២៥ |
| `Kh_Health_Center` | `Health/` | មណ្ឌលសុខភាព ៩៥៦ ទូទាំងប្រទេស |
| `Census_Village` | `Census_2008/` | ភូមិ ១៤ ០៧៣ ជាមួយប្រជាជនឆ្នាំ ២០០៨ (`TOTPOP`) |

ស្រទាប់ទាំងអស់ប្រើ **EPSG:32648** ដែលមានឯកតាជាម៉ែត្រ។ ដូច្នេះ ចម្ងាយបាហ្វ័រអាចបញ្ចូលជាម៉ែត្រ ឬគីឡូម៉ែត្រដោយផ្ទាល់។

!!! warning "ពិនិត្យ CRS មុនបង្កើតបាហ្វ័រ"
    បើស្រទាប់ប្រើ CRS ភូមិសាស្ត្រ (ឧទាហរណ៍ EPSG:4326) ឯកតាគឺជា **ដឺក្រេ** មិនមែនម៉ែត្រទេ។ បាហ្វ័រ «៥» នឹងមានន័យថា ៥ ដឺក្រេ ឬប្រហែល ៥៥០ គីឡូម៉ែត្រ។ ទ្រឹស្ដី CRS យោងទៅសៀវភៅទី១។

## សកម្មភាពទី១៖ រៀបចំតំបន់សិក្សា · ១៥ នាទី

1. បង្កើតគម្រោងថ្មី ហើយរក្សាទុកជា `lab-10.qgz` ក្នុងថតដាច់ដោយឡែក។
2. បន្ថែមស្រទាប់ទាំងបី ពីផ្ទាំង **Browser**។
3. បើក **Processing Toolbox** ហើយស្វែងរក **Extract by expression**។
4. ទាញខេត្តកំពង់ឆ្នាំងចេញពី `Kh_Province_Boundary`៖

    ```text
    "ProvGis" = 'KH04'
    ```

    រក្សាទុកលទ្ធផលជា `kc_province.gpkg`។

5. ទាញភូមិរបស់ខេត្តនេះចេញពី `Census_Village` ដោយប្រើលេខកូដភូមិ៖

    ```text
    left("VILL_CODE", 2) = '04'
    ```

    រក្សាទុកជា `kc_villages.gpkg`។

6. ចុចស្ដាំលើ `kc_villages` → **Show Feature Count** ហើយកត់ត្រាចំនួនភូមិ។

**សំណួរ៖** ហេតុអ្វីបានជាយើងប្រើលេខកូដ `VILL_CODE` ជំនួសឲ្យការជ្រើសរើសភូមិតាមព្រំខេត្ត? · តើវិធីទាំងពីរអាចផ្ដល់លទ្ធផលខុសគ្នាក្នុងករណីណា?

## សកម្មភាពទី២៖ បង្កើតបាហ្វ័រ ៥ គីឡូម៉ែត្រ · ១៥ នាទី

1. ចូល **Vector → Geoprocessing Tools → Buffer**។
2. កំណត់៖

    | ប៉ារ៉ាម៉ែត្រ | តម្លៃ |
    |---|---|
    | Input layer | `Kh_Health_Center` (**ទូទាំងប្រទេស** មិនមែនតែខេត្តនេះទេ) |
    | Distance | `5` · ឯកតា **Kilometers** |
    | Segments | `5` (លំនាំដើម) |
    | Dissolve result | ✓ |

3. រក្សាទុកជា `hc_buffer_5km.gpkg`។
4. ដាក់ស្រទាប់បាហ្វ័រនៅក្រោមភូមិ ហើយប្រើពណ៌ពាក់កណ្ដាលថ្លា (opacity ប្រហែល ៤០%)។
5. ពង្រីកទៅខេត្តកំពង់ឆ្នាំង ហើយសង្កេតតំបន់ដែលគ្មានបាហ្វ័រគ្របដណ្ដប់។

**សំណួរ៖** តើ **Dissolve result** ផ្លាស់ប្ដូរអ្វីខ្លះក្នុងតារាងគុណលក្ខណៈ? · បើមិនរំលាយ តើភូមិដែលនៅក្នុងបាហ្វ័រពីរត្រួតគ្នា នឹងត្រូវរាប់ប៉ុន្មានដង?

## សកម្មភាពទី៣៖ ជ្រើសរើសភូមិនៅក្រៅបាហ្វ័រ · ១៥ នាទី

1. ចូល **Vector → Research Tools → Select by Location**។
2. កំណត់៖

    | ប៉ារ៉ាម៉ែត្រ | តម្លៃ |
    |---|---|
    | Select features from | `kc_villages` |
    | Where the features | **are disjoint** |
    | By comparing to the features from | `hc_buffer_5km` |
    | Modify current selection by | creating new selection |

3. កត់ត្រាចំនួនភូមិដែលបានជ្រើសរើស (មើលនៅរបារខាងក្រោម ឬចំណងជើង Attribute Table)។
4. បើក **View → Panels → Statistics**។ ជ្រើស `kc_villages` វាល `TOTPOP` ហើយធីក **Selected features only**។ កត់ត្រាតម្លៃ **Sum**។
5. ចុចស្ដាំលើ `kc_villages` → **Export → Save Selected Features As** ហើយរក្សាទុកជា `kc_villages_far.gpkg`។

## សកម្មភាពទី៤៖ ពិនិត្យឥទ្ធិពលគែម · ១៥ នាទី

ប្រជាជនមិនស្គាល់ព្រំខេត្តទេ។ ភូមិនៅជិតព្រំខេត្ត អាចទៅមណ្ឌលសុខភាពនៅខេត្តជិតខាងបាន។ សកម្មភាពនេះវាស់ថា ការមើលរំលងមណ្ឌលសុខភាពខេត្តជិតខាង ប៉ះពាល់លទ្ធផលប៉ុណ្ណា។

1. ចូល **Vector → Research Tools → Extract by Location**។ ទាញ `Kh_Health_Center` ដែល **are within** `kc_province` → រក្សាទុកជា `kc_health_centres.gpkg`។ កត់ត្រាចំនួន។
2. បង្កើតបាហ្វ័រ ៥ គីឡូម៉ែត្រ (Dissolve) ពី `kc_health_centres` → `kc_hc_buffer_5km.gpkg`។
3. ធ្វើ **Select by Location** ម្ដងទៀតដូចសកម្មភាពទី៣ ប៉ុន្តែប្រៀបធៀបជាមួយ `kc_hc_buffer_5km`។
4. កត់ត្រាចំនួនភូមិ និងប្រជាជន ហើយប្រៀបធៀបជាមួយលទ្ធផលសកម្មភាពទី៣។

**សំណួរ៖** តើមានភូមិប៉ុន្មាន ដែលត្រូវបានចាត់ទុកថា «ឆ្ងាយ» ដោយខុស ពេលប្រើតែមណ្ឌលសុខភាពក្នុងខេត្ត? · តើស្រុកណាដែលរងឥទ្ធិពលខ្លាំងជាងគេ ហើយហេតុអ្វី?

## ផែនទីអន្តរកម្មសម្រាប់ផ្ទៀងផ្ទាត់

ប្រើផែនទីនេះ **ក្រោយពេល** ធ្វើសកម្មភាពទី២ និងទី៣ រួច ដើម្បីប្រៀបធៀបជាមួយលទ្ធផលក្នុង QGIS។ ចុចលើចំណុចដើម្បីមើលព័ត៌មាន ហើយប្រើប៊ូតុងស្រទាប់នៅជ្រុងខាងលើស្ដាំ ដើម្បីបិទ ឬបើកស្រទាប់។ ចុចលើផែនទីម្ដង ដើម្បីអាចពង្រីកដោយកង់កណ្ដុរ។

## សកម្មភាពទី៥៖ គណនាចម្ងាយទៅមណ្ឌលសុខភាពជិតបំផុត · ២០ នាទី

បាហ្វ័រប្រាប់តែ «នៅក្នុង» ឬ «នៅក្រៅ» ប៉ុណ្ណោះ។ សកម្មភាពនេះគណនាចម្ងាយពិតប្រាកដសម្រាប់ភូមិនីមួយៗ។

1. ក្នុង **Processing Toolbox** ស្វែងរក **Distance to nearest hub (points)**។
2. កំណត់៖

    | ប៉ារ៉ាម៉ែត្រ | តម្លៃ |
    |---|---|
    | Source points layer | `kc_villages` |
    | Destination hubs layer | `Kh_Health_Center` |
    | Hub layer name attribute | `FACILITNAM` |
    | Measurement unit | **Kilometers** |

3. រក្សាទុកជា `kc_villages_dist.gpkg`។ លទ្ធផលមានវាលថ្មីពីរ៖ `HubName` (ឈ្មោះមណ្ឌលសុខភាពជិតបំផុត) និង `HubDist` (ចម្ងាយ គម)។
4. បើក **Field Calculator** លើ `kc_villages_dist`។ បង្កើតវាលអក្សរថ្មី `dist_class`៖

    ```text
    CASE
      WHEN "HubDist" <= 2  THEN '1: 0-2 km'
      WHEN "HubDist" <= 5  THEN '2: 2-5 km'
      WHEN "HubDist" <= 10 THEN '3: 5-10 km'
      ELSE '4: >10 km'
    END
    ```

5. ក្នុង **Processing Toolbox** ប្រើ **Statistics by categories**៖ វាលគណនា `TOTPOP` · វាលចាត់ថ្នាក់ `dist_class`។ បើកតារាងលទ្ធផល ហើយយក `count` និង `sum`។
6. តម្រៀប Attribute Table តាម `HubDist` ពីធំទៅតូច ដើម្បីរកភូមិដែលនៅឆ្ងាយបំផុត។
7. ដាក់និមិត្តសញ្ញា **Categorized** លើ `dist_class` ដោយប្រើពណ៌ពីស្រាលទៅដិត។

**សំណួរ៖** ចំនួនភូមិលើសពី ៥ គម ក្នុងសកម្មភាពនេះ ស្មើនឹងសកម្មភាពទី៣ ឬទេ? បើខុសគ្នាមួយ ឬពីរភូមិ តើមកពីមូលហេតុអ្វី? (ជំនួយ៖ តើ **Segments = 5** បង្កើតរង្វង់ពិតប្រាកដឬទេ?)

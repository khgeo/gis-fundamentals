# លំហាត់ទី២៖ ប្រៀបធៀបគំរូវ៉ិចទ័រ និងរ៉ាស្ទ័រ

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី២៖ គំរូទិន្នន័យវ៉ិចទ័រ និងរ៉ាស្ទ័រ](../lessons/lesson-02.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR

## គោលបំណង

- ពិនិត្យធរណីមាត្រ និងតារាងគុណលក្ខណៈរបស់ស្រទាប់វ៉ិចទ័រ។
- រកកំហុសធរណីមាត្រ និងកែវា។
- ពិនិត្យរចនាសម្ព័ន្ធ និងគុណភាពបង្ហាញរបស់រ៉ាស្ទ័រ។
- ប្រៀបធៀបផ្ទៃដែលគណនាបានពីទាំងពីរ រួចពន្យល់ភាពខុសគ្នា។

## ឯកសារដែលប្រើ

| ស្រទាប់ | ប្រភេទ | ខ្លឹមសារ |
|---|---|---|
| `parcels` | វ៉ិចទ័រ ពហុកោណ | ក្បាលដីស្រែសន្មត ១២ |
| `parcels_errors` | វ៉ិចទ័រ ពហុកោណ | ដូចខាងលើ តែមានកំហុសបញ្ចូលដោយចេតនា |
| `roads` | វ៉ិចទ័រ បន្ទាត់ | បណ្ដាញផ្លូវសន្មត មានលើសចុង និងខ្វះចុង |
| `landuse_10m` | រ៉ាស្ទ័រ | ផែនទីប្រើប្រាស់ដីសន្មត ១០ ម៉ែត្រ |

## សកម្មភាពទី១៖ ពិនិត្យធរណីមាត្រវ៉ិចទ័រ · ១៥ នាទី

1. បន្ថែមស្រទាប់ `parcels` ហើយបើក **Attribute Table**។
2. បើក Field Calculator រួចបង្កើតវាលថ្មី `area_m2` ជាប្រភេទ *Decimal*៖ `$area`
3. កត់ត្រាផ្ទៃរបស់ក្បាលដីដែលមានលេខសម្គាល់ `P01`។
4. ប្ដូរ CRS បង្ហាញទៅ **EPSG:4326** រួចគណនា `$area` ម្ដងទៀតក្នុងវាលថ្មី។

**សំណួរ៖** តើតម្លៃទាំងពីរខុសគ្នាដែរឬទេ? ហេតុអ្វី? តើមួយណាអាចប្រើសម្រាប់រាយការណ៍ជាហិកតា?

!!! danger "អន្ទាក់ធម្មតាបំផុត"
    `$area` គណនាក្នុងឯកតារបស់ CRS។ ក្នុង EPSG:4326 ឯកតាជា **អង្សា** មិនមែនម៉ែត្រទេ។ លទ្ធផលនឹងជាលេខតូចឥតន័យ។ ត្រូវប្រើ CRS ព្យាករដូចជា EPSG:32648។

## សកម្មភាពទី២៖ រក និងកែកំហុសធរណីមាត្រ · ២០ នាទី

1. បន្ថែម `parcels_errors` និង `roads`។
2. រត់ **Vector → Geometry Tools → Check Validity** លើ `parcels_errors`។
3. កត់ត្រាចំនួន និងប្រភេទកំហុសដែលរកឃើញ។
4. រត់ **Processing → Fix Geometries** រួចប្រៀបធៀបផ្ទៃសរុបមុន និងក្រោយ។
5. ពង្រីកមើលចំណុចប្រសព្វផ្លូវ រកលើសចុង និងខ្វះចុងដោយភ្នែក។

**សំណួរ៖** តើផ្ទៃសរុបប្រែប្រួលប៉ុន្មានភាគរយក្រោយការកែ? តើកំហុសខ្វះចុងនឹងប៉ះពាល់ដល់ការវិភាគផ្លូវយ៉ាងដូចម្ដេច?

## សកម្មភាពទី៣៖ ពិនិត្យរ៉ាស្ទ័រ · ១៥ នាទី

1. បន្ថែម `landuse_10m` ហើយបើក **Properties → Information**។
2. កត់ត្រា៖ ទំហំក្រឡា · ចំនួនជួរដេក និងជួរឈរ · CRS · តម្លៃ NoData។
3. ប្រើឧបករណ៍ **Identify** ចុចលើក្រឡាមួយចំនួន រួចកត់ត្រាតម្លៃ។
4. ពង្រីករហូតឃើញក្រឡាដាច់ៗពីគ្នា រួចសង្កេតព្រំដែនជាជណ្ដើរ។

**សំណួរ៖** តើក្រឡាមួយគ្របផ្ទៃប៉ុន្មានម៉ែត្រការ៉េ? តើផ្លូវទទឹង ៦ ម៉ែត្រមើលឃើញទេ? ហេតុអ្វី?

## សកម្មភាពទី៤៖ ប្រៀបធៀប និងសរសេរ · ១០ នាទី

1. រាប់ក្រឡាថ្នាក់ស្រែក្នុងតំបន់ក្បាលដី `P01` (ប្រើ Identify ឬ Zonal Histogram)។
2. គុណនឹង ១០០ ម៉ែត្រការ៉េ ដើម្បីបានផ្ទៃប៉ាន់ស្មាន។
3. ប្រៀបធៀបនឹងផ្ទៃវ៉ិចទ័រពីសកម្មភាពទី១។
4. សរសេរ ៤ ទៅ ៦ ប្រយោគ៖ តួលេខទាំងពីរ · ភាពខុសគ្នាជាភាគរយ · មូលហេតុ · មួយណាដែលអ្នកនឹងរាយការណ៍ និងហេតុអ្វី។

## លទ្ធផលត្រូវប្រគល់

- គម្រោង QGIS រក្សាទុកជា `lesson-02.qgz`។
- តារាងប្រៀបធៀបផ្ទៃវ៉ិចទ័រ និងរ៉ាស្ទ័រ។
- បញ្ជីកំហុសធរណីមាត្រដែលរកឃើញ និងលទ្ធផលក្រោយការកែ។
- សេចក្ដីសន្និដ្ឋានខ្លី។

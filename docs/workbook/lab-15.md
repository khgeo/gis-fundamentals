# លំហាត់ទី១៥៖ រៀបចំ ចែករំលែក និងចាប់ផ្ដើមគម្រោងបញ្ចប់វគ្គ

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១៥៖ ការគ្រប់គ្រងគម្រោង ការចែករំលែក និងគម្រោងបញ្ចប់វគ្គ](../lessons/lesson-15.md)

## ស្ថានភាព

អ្នកបានធ្វើលំហាត់ ១៤ ហើយ។ ឥឡូវនេះ អ្នកត្រូវផ្ញើគម្រោងមួយទៅមិត្តរួមក្រុម ដែលប្រើកុំព្យូទ័រផ្សេង។ ពេលគេបើក **ស្រទាប់ទាំងអស់ត្រូវតែបង្ហាញ** ដោយមិនមានសញ្ញាក្រហម «Unavailable layer»។ បន្ទាប់មក អ្នកចាប់ផ្ដើមគម្រោងបញ្ចប់វគ្គរបស់ខ្លួន។

## គោលបំណង

- រៀបចំរចនាសម្ព័ន្ធថត និងឈ្មោះឯកសារដែលមានស្តង់ដារ។
- ប្រើផ្លូវ relative និងខ្ចប់ស្រទាប់ទៅក្នុង GeoPackage តែមួយ។
- ជួសជុលស្រទាប់ដែលបាត់ (Handle Unavailable Layers)។
- សរសេរសំណើគម្រោងបញ្ចប់វគ្គ ដែលមានសំណួរ ទិន្នន័យ វិធីសាស្ត្រ និងផែនការពេល។

## សកម្មភាពទី១៖ រចនាសម្ព័ន្ធថត · ២០ នាទី

បង្កើតរចនាសម្ព័ន្ធនេះ ហើយផ្លាស់ទីឯកសារលំហាត់ទី១០ ចូល៖

```text
D:/GIS/lab10_health_access/
├── lab10_health_access.qgz
├── data/
│   ├── raw/          ទិន្នន័យដើម (មិនកែ)
│   └── processed/    លទ្ធផលពី Processing
├── maps/             PDF PNG
├── docs/             របាយការណ៍ មេតាទិន្នន័យ
└── README.txt
```

ក្បួនដាក់ឈ្មោះ៖ អក្សរតូច · គ្មានដកឃ្លា · គ្មានអក្សរខ្មែរ · អ្វី_កន្លែង_ឆ្នាំ ឧ. `villages_far_kc_2008.gpkg`

## សកម្មភាពទី២៖ ផ្លូវ relative និងស្រទាប់ដែលបាត់ · ២០ នាទី

1. **Project → Properties → General → Save paths** → **Relative**។ រក្សាទុកគម្រោង។
2. បិទ QGIS។ ប្ដូរឈ្មោះថត `data/processed` ទៅ `data/output`។ បើកគម្រោងម្ដងទៀត។
3. ក្នុងប្រអប់ **Handle Unavailable Layers** ចុច **Auto-Find** ឬ **Browse** ដើម្បីជួសជុល។ រក្សាទុក។
4. ចម្លងថតទាំងមូលទៅ USB ឬថតផ្សេង ហើយបើកគម្រោងពីទីនោះ។ តើស្រទាប់នៅតែបង្ហាញឬទេ?

**សំណួរ៖** ហេតុអ្វីផ្លូវ absolute (`C:/Users/...`) ធ្វើឲ្យគម្រោងខូចពេលផ្ញើទៅអ្នកផ្សេង?

## សកម្មភាពទី៣៖ ខ្ចប់គម្រោង · ២០ នាទី

1. **Processing → Package layers**៖ ជ្រើសស្រទាប់វ៉ិចទ័រទាំងអស់ · Destination `lab10_package.gpkg` · ធីក **Save layer styles into GeoPackage**។
2. បង្កើតគម្រោងថ្មី បន្ថែមស្រទាប់ពី `lab10_package.gpkg` ហើយពិនិត្យថានិមិត្តសញ្ញានៅដដែល។
3. **Project → Save To → GeoPackage** → ជ្រើស `lab10_package.gpkg`។ ឥឡូវនេះ ទិន្នន័យ រចនាប័ទ្ម និងគម្រោង ស្ថិតក្នុងឯកសារតែមួយ។
4. សរសេរ `README.txt`៖ ចំណងជើង · អ្នកធ្វើ · ថ្ងៃ · CRS · ប្រភពទិន្នន័យ · របៀបបើក · ឯកសារនីមួយៗមានអ្វី។

    ដើម្បីចែករំលែកផែនទីអន្តរកម្ម (ដូចផែនទីក្នុងសៀវភៅនេះ) ដំឡើង Plugin **qgis2web** ហើយនាំចេញជាទំព័រ Leaflet។ ទំព័រនោះអាចដាក់លើ GitHub Pages ដោយឥតគិតថ្លៃ។ ត្រូវប្រាកដថាទិន្នន័យអាចផ្សព្វផ្សាយបាន (អាជ្ញាបណ្ណ និងឯកជនភាព)។

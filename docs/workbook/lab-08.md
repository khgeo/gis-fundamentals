# លំហាត់ទី៨៖ អ្នកស៊ើបអង្កេតទិន្នន័យ៖ រកកំហុសប្រាំ

## ស្ថានភាព

មុនប្រើសំណុំទិន្នន័យ `Cambodia` ក្នុងរបាយការណ៍ផ្លូវការ អ្នកត្រូវធ្វើ **សវនកម្មគុណភាព**។ ទិន្នន័យពិតតែងមានកំហុស។ ភារកិច្ចរបស់អ្នក គឺរក កត់ត្រា ពន្យល់ផលប៉ះពាល់ និងស្នើវិធីកែ ដោយ **មិនលុបទិន្នន័យដើម**។

## គោលបំណង

- ពិនិត្យភាពពេញលេញ ភាពស៊ីសង្វាក់ ភាពត្រឹមត្រូវទីតាំង និងភាពត្រឹមត្រូវគុណលក្ខណៈ។
- ប្រើឧបករណ៍ Check Validity និង Fix Geometries។
- ប្រៀបធៀបស្រទាប់ពីរ ដើម្បីរកភាពមិនស៊ីគ្នា។
- សរសេរមេតាទិន្នន័យ និងរបាយការណ៍កំហុស។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។ ស្រទាប់ទាំងអស់ប្រើ **EPSG:32648**។

|---|---|
| `Census_Prov_point` `Kh_Province_Boundary` | `Census_2008/` `Admin/` |
| `Kh_Health_Center` | `Health/` |
| `Water/Flood2011` | `Water/` |
| `KKG_LC1997` `KKG_LC2003` `KKG_LC2015` | `Landuse/` |
| `Kh_School` | `School/` |

## ករណីទី១៖ ខេត្តស្ទួន · ២០ នាទី

1. បើក Attribute Table នៃ `Census_Prov_point`។
2. **Processing → List unique values** លើវាល `ProvGis`។ មានលេខកូដប៉ុន្មាន? រំពឹងប៉ុន្មាន?
3. ប្រៀបធៀបជួរដែលមានលេខកូដស្ទួន ជាមួយ `Kh_Province_Boundary` (ឈ្មោះ លេខកូដ ផ្ទៃ ប្រជាជន)។
4. ពិនិត្យថាទីតាំងចំណុចត្រឹមត្រូវឬទេ ដោយដាក់ស្រទាប់ទាំងពីរលើគ្នា។

**កត់ត្រា៖** ជួរណាខុស · វាលណាខុស · ប្រភេទកំហុស (ទីតាំង ឬ គុណលក្ខណៈ) · ផលប៉ះពាល់ បើយកទៅធ្វើផែនទីប្រជាជន។

## ករណីទី២៖ ឈ្មោះខេត្តមិនស៊ីនឹងលេខកូដ · ២០ នាទី

1. **Processing → Statistics by categories** លើ `Kh_Health_Center`៖ Field(s) with categories `PCODE` និង `PNAME`។
2. រកលេខ `PCODE` ដែលមាន `PNAME` ច្រើនជាងមួយ។
3. ជ្រើសកំណត់ត្រាខុស ឧទាហរណ៍៖

    ```text
    "PCODE" = 2 AND "PNAME" <> 'Battambang'
    ```

4. ប្រើ **Select by Location** ជាមួយ `Kh_Province_Boundary` ដើម្បីដឹងថាចំណុចនោះនៅខេត្តណាពិតប្រាកដ។

**សំណួរ៖** វាលមួយណាដែលអ្នកជឿ៖ `PCODE` `PNAME` ឬទីតាំង? ហេតុអ្វី?

## ករណីទី៣៖ ធរណីមាត្រមិនត្រឹមត្រូវ · ២០ នាទី

1. **Vector → Geometry Tools → Check Validity**៖ Input `Flood2011` · Method **GEOS**។
2. រាប់វត្ថុក្នុងលទ្ធផល **Invalid output**។ បើកស្រទាប់ **Error output** ដើម្បីមើលទីតាំងកំហុស។
3. សាកល្បង **Clip** `Flood2011` ជាមួយខេត្តមួយ។ តើមានសារកំហុសឬទេ?
4. **Processing → Fix geometries** → `flood2011_fixed.gpkg` ។ ធ្វើ Check Validity ម្ដងទៀត។

## ករណីទី៤៖ ឈ្មោះថ្នាក់មិនស៊ីគ្នា · ១៥ នាទី

1. **List unique values** លើ `LC97` `LC03` `LC15` ក្នុងស្រទាប់កោះកុងទាំងបី។
2. រកឈ្មោះថ្នាក់ដែលមានអត្ថន័យដូចគ្នា ប៉ុន្តែសរសេរខុសគ្នា និងអក្ខរាវិរុទ្ធខុស។
3. សរសេរកន្សោម Field Calculator ដែលកែឈ្មោះទាំងនោះទៅជាឈ្មោះស្តង់ដារ។

## ករណីទី៥៖ សាលាដែលនៅក្រៅខេត្តខ្លួន · ១០ នាទី

1. ជ្រើស `Kh_School` ដោយ `"PROVINCE" = 'Kampong Chhnang'` → កត់ត្រាចំនួន។
2. **Select by Location**៖ `Kh_School` ដែល **are within** ខេត្ត KH04 → កត់ត្រាចំនួន។
3. រកសាលាដែលមានក្នុងការជ្រើសទីមួយ ប៉ុន្តែមិនមានក្នុងទីពីរ។ ពង្រីកមើលទីតាំងរបស់វា។

## របាយការណ៍ និងមេតាទិន្នន័យ · ១៥ នាទី

1. បំពេញរបាយការណ៍កំហុស៖

    | # | ស្រទាប់ | កំហុស | ប្រភេទគុណភាព | ផលប៉ះពាល់ | វិធីកែដែលស្នើ |
    |---|---|---|---|---|---|
    | ១ | | | | | |

    ប្រភេទគុណភាព៖ ភាពត្រឹមត្រូវទីតាំង · ភាពត្រឹមត្រូវគុណលក្ខណៈ · ភាពស៊ីសង្វាក់តក្កវិជ្ជា · ភាពពេញលេញ · ប្រភពដើម (lineage)

2. បើក **Layer Properties → Metadata** នៃ `flood2011_fixed`។ បំពេញ Title · Abstract · Keywords · Contact · Lineage (សរសេរថាបានកែធរណីមាត្រដោយ Fix geometries ថ្ងៃណា)។ **Save as Default**។

# លំហាត់ទី១១៖ ព្រៃឈើខេត្តកោះកុងបាត់បង់ទៅណា?

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១១៖ ការត្រួតស្រទាប់ និង Spatial join](../lessons/lesson-11.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១១០ នាទី

## ស្ថានភាព

ខេត្តកោះកុងជាខេត្តដែលមានព្រៃឈើច្រើនជាងគេមួយក្នុងប្រទេសកម្ពុជា។ អង្គការបរិស្ថានមួយចង់ដឹងចម្លើយសំណួរបី៖

1. ចន្លោះឆ្នាំ ១៩៩៧ និង ២០១៥ ព្រៃឈើបានប្ដូរទៅជាក្រប់ដីប្រភេទអ្វីខ្លះ និងប៉ុន្មានហិកតា?
2. តើតំបន់ការពារធម្មជាតិ ពិតជាបាត់បង់ព្រៃតិចជាងតំបន់ក្រៅតំបន់ការពារឬទេ?
3. តើឃុំណាខ្លះបាត់បង់ព្រៃច្រើនជាងគេ?

## គោលបំណង

- កាត់ (Clip) ស្រទាប់ឲ្យត្រូវនឹងតំបន់សិក្សា ហើយពិនិត្យវិសាលភាពទិន្នន័យ។
- ប្រើ Intersection ដើម្បីបង្កើតស្រទាប់ការផ្លាស់ប្ដូរ និងម៉ាទ្រីសផ្លាស់ប្ដូរ (change matrix)។
- ដឹងថា **តម្លៃផ្ទៃចាស់មិនធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិ** ក្រោយការត្រួតស្រទាប់។
- ប្រៀបធៀប Spatial join និងការត្រួតស្រទាប់ ហើយពន្យល់ថាពេលណាប្រើមួយណា។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។

| ស្រទាប់ | ថត | ខ្លឹមសារ |
|---|---|---|
| `KKG_LC1997` | `Landuse/` | ក្រប់ដី ៥ ថ្នាក់ ឆ្នាំ ១៩៩៧ (MRC) · វាល `LC97` |
| `KKG_LC2015` | `Landuse/` | ក្រប់ដី ៥ ថ្នាក់ ឆ្នាំ ២០១៥ (MoE) · វាល `LC15` |
| `Kh_Province_Boundary` | `Admin/` | ព្រំខេត្ត |

| `Kh_Commune_area` | `Admin/` | ព្រំឃុំ សង្កាត់ |

**សរសេរការសង្កេតបី៖** តំបន់ណាប្ដូរពណ៌ខ្លាំងជាងគេ? · ការផ្លាស់ប្ដូរកើតឡើងជិតផ្លូវ ឆ្នេរ ឬជ្រៅក្នុងភ្នំ? · តើមានតំបន់ណាដែល «ពណ៌ត្រឡប់ជាព្រៃវិញ» ទេ?

## សកម្មភាពទី១៖ កាត់ក្រប់ដីឲ្យត្រូវនឹងខេត្ត · ១៥ នាទី

1. បង្កើតគម្រោងថ្មី `lab-11.qgz` ហើយបន្ថែមស្រទាប់ទាំងប្រាំ។
2. ដាក់ `Kh_Province_Boundary` នៅខាងលើ ជាព្រំដែនគ្មានពណ៌ផ្ទៃ។ សង្កេតថាស្រទាប់ក្រប់ដី **លាតហួសព្រំខេត្តកោះកុង**។
3. ប្រើ **Extract by expression** លើ `Kh_Province_Boundary`៖ `"ProvGis" = 'KH09'` → `kk_province.gpkg`
4. ចូល **Vector → Geoprocessing Tools → Clip**។ Input `KKG_LC1997` · Overlay `kk_province` → `kk_lc1997.gpkg`
5. ធ្វើដូចគ្នាសម្រាប់ `KKG_LC2015` → `kk_lc2015.gpkg`
6. ក្នុងស្រទាប់នីមួយៗ បង្កើតវាល `area_ha` (Decimal) ដោយ Field Calculator៖

    ```text
    $area / 10000
    ```

7. កត់ត្រាផ្ទៃព្រៃឈើ (`Forest cover`) ឆ្នាំ ១៩៩៧ និង ២០១៥។

**សំណួរ៖** ស្រទាប់ក្រប់ដីលាតចូលខេត្តណាខ្លះ? · បើមិន Clip តើលទ្ធផលផ្ទៃព្រៃឈើ «ខេត្តកោះកុង» នឹងខុសយ៉ាងដូចម្ដេច?

## សកម្មភាពទី២៖ បង្កើតស្រទាប់ការផ្លាស់ប្ដូរ · ២០ នាទី

1. ចូល **Vector → Geoprocessing Tools → Intersection**។ Input `kk_lc1997` · Overlay `kk_lc2015` → `kk_change.gpkg`
2. បើក Attribute Table។ ស្រទាប់ថ្មីមានវាល `LC97` និង `LC15` ព្រមទាំងវាល `area_ha` ពីរ (`area_ha` និង `area_ha_2`)។
3. **កុំប្រើវាល `area_ha` ទាំងពីរនេះ!** វាជាផ្ទៃរបស់ពហុកោណដើមមុនការត្រួតស្រទាប់។ បង្កើតវាលថ្មី `chg_ha`៖

    ```text
    $area / 10000
    ```

4. បង្កើតវាលអក្សរ `change`៖

    ```text
    "LC97" || ' → ' || "LC15"
    ```

5. ដាក់និមិត្តសញ្ញា **Categorized** លើ `change`។ បិទការបង្ហាញថ្នាក់ដែលមិនប្ដូរ (ឧទាហរណ៍ `Forest cover → Forest cover`) ដើម្បីឃើញតែការផ្លាស់ប្ដូរ។

!!! danger "អន្ទាក់ធម្មតាបំផុតនៃការត្រួតស្រទាប់"
    Intersection ចម្លងគុណលក្ខណៈពីស្រទាប់ដើម **ទាំងតម្លៃចាស់**។ វាល `area_ha` ក្នុង `kk_change` នៅតែជាផ្ទៃព្រៃឈើទាំងមូលឆ្នាំ ១៩៩៧ មិនមែនផ្ទៃនៃពហុកោណថ្មីទេ។ ត្រូវគណនាផ្ទៃ **ក្រោយ** ការត្រួតស្រទាប់ជានិច្ច។

## សកម្មភាពទី៣៖ ម៉ាទ្រីសផ្លាស់ប្ដូរ · ២០ នាទី

1. ក្នុង **Processing Toolbox** បើក **Statistics by categories**។
2. Input `kk_change` · Field to calculate statistics on `chg_ha` · Field(s) with categories៖ ជ្រើស **ទាំង `LC97` និង `LC15`**។
3. បើកតារាងលទ្ធផល។ ជួរនីមួយៗជាគូ «ឆ្នាំ ១៩៩៧ → ឆ្នាំ ២០១៥» ជាមួយ `sum`។
4. បំពេញម៉ាទ្រីស ៥ × ៥ ក្នុងក្រដាស ឬ Excel៖ ជួរដេក = ១៩៩៧ · ជួរឈរ = ២០១៥។
5. ផលបូកជួរដេកនីមួយៗ ត្រូវស្មើផ្ទៃថ្នាក់នោះឆ្នាំ ១៩៩៧ (សកម្មភាពទី១)។ បើមិនស្មើ ពិនិត្យជំហានម្ដងទៀត។

ប្រៀបធៀបម៉ាទ្រីសរបស់អ្នកជាមួយម៉ាទ្រីសខាងក្រោម។ **ចុចលើក្រឡា** ដើម្បីអានអត្ថន័យ។ ក្រឡាក្នុងជួរ **ព្រៃឈើ** ក៏បន្លិចការបាត់បង់ប្រភេទនោះលើផែនទីក្នុងសកម្មភាពទី៥ផងដែរ។

<div class="change-matrix" data-matrix="lab-11"></div>

**សំណួរ៖** ព្រៃឈើប្ដូរទៅជាថ្នាក់ណាច្រើនជាងគេ? · ព្រៃឈើ ២៣ ពាន់ហិកតា «ក្លាយជាទឹក»។ តើអ្វីអាចជាមូលហេតុពិត និងអ្វីអាចជាកំហុសចាត់ថ្នាក់? · តើមានព្រៃកើតឡើងវិញប៉ុន្មាន?

## សកម្មភាពទី៤៖ ការបាត់បង់ព្រៃក្នុង និងក្រៅតំបន់ការពារ · ២០ នាទី

1. ប្រើ **Extract by expression** លើ `kk_change`៖

    ```text
    "LC97" = 'Forest cover' AND "LC15" <> 'Forest cover'
    ```

    → `kk_forest_loss.gpkg` · កត់ត្រាផ្ទៃសរុប។

2. **Intersection**៖ Input `kk_forest_loss` · Overlay `Kh_PA_MOE2018` → `loss_in_pa.gpkg`
3. គណនា `pa_ha = $area / 10000` ម្ដងទៀត (ហេតុផលដូចសកម្មភាពទី២)។
4. **Statistics by categories**៖ `pa_ha` តាម `Name_E` → រកតំបន់ការពារដែលបាត់បង់ព្រៃច្រើនជាងគេ។
5. ដើម្បីប្រៀបធៀបដោយយុត្តិធម៌ ត្រូវគណនា **អត្រា** មិនមែនចំនួនដុល៖
    - ទាញព្រៃឈើឆ្នាំ ១៩៩៧ ពី `kk_lc1997` (`"LC97" = 'Forest cover'`) → **Clip** ជាមួយ `Kh_PA_MOE2018` → គណនាផ្ទៃ = ព្រៃឆ្នាំ ១៩៩៧ ក្នុងតំបន់ការពារ
    - ព្រៃក្រៅតំបន់ការពារ = ព្រៃសរុបឆ្នាំ ១៩៩៧ − ព្រៃក្នុងតំបន់ការពារ
    - អត្រាបាត់បង់ = ផ្ទៃបាត់បង់ ÷ ផ្ទៃព្រៃឆ្នាំ ១៩៩៧ × ១០០

    | | ព្រៃ ១៩៩៧ (ហ.ត) | បាត់បង់ (ហ.ត) | អត្រាបាត់បង់ (%) |
    |---|---:|---:|---:|
    | ក្នុងតំបន់ការពារ | | | |
    | ក្រៅតំបន់ការពារ | | | |

**សំណួរ៖** ស្រទាប់តំបន់ការពារជាព្រំដែនឆ្នាំ ២០១៨។ តំបន់មួយចំនួន ដូចជាឧទ្យានជាតិជួរភ្នំក្រវាញខាងត្បូង និងដែនជម្រកសត្វព្រៃតាតៃ ត្រូវបានបង្កើតនៅឆ្នាំ ២០១៦ ក្រោយរយៈពេលសិក្សា។ តើការពិតនេះប៉ះពាល់ដល់ការសន្និដ្ឋានថា «តំបន់ការពារបានការពារព្រៃ» យ៉ាងដូចម្ដេច? · តំបន់ណាដែលមានតាំងពីឆ្នាំ ១៩៩៣ ប៉ុន្តែនៅតែបាត់បង់ព្រៃច្រើន?

## សកម្មភាពទី៥៖ Spatial join ឬ ការត្រួតស្រទាប់? · ២០ នាទី

**ក. សាកល្បង Spatial join (វិធីខុស)**

1. **Extract by expression** លើ `Kh_Commune_area`៖ `"ProvGis" = 'KH09'` → `kk_communes.gpkg`
2. ក្នុង **Processing Toolbox** បើក **Join attributes by location (summary)**៖

    | ប៉ារ៉ាម៉ែត្រ | តម្លៃ |
    |---|---|
    | Join to features in | `kk_communes` |
    | Where the features | intersect |
    | By comparing to | `kk_forest_loss` |
    | Fields to summarise | `chg_ha` |
    | Summaries to calculate | sum |

3. បើកតារាងលទ្ធផល ហើយមើលវាល `chg_ha_sum`។ **តើតម្លៃទាំងនេះសមហេតុផលទេ?** ប្រៀបធៀបជាមួយផ្ទៃឃុំខ្លួនឯង។

**ខ. ការត្រួតស្រទាប់ (វិធីត្រូវ)**

4. **Intersection**៖ Input `kk_forest_loss` · Overlay `kk_communes` → `loss_by_commune.gpkg`
5. គណនា `com_ha = $area / 10000`
6. **Statistics by categories**៖ `com_ha` តាម `COM_NAME` → តម្រៀបពីធំទៅតូច។

**សំណួរ៖** ហេតុអ្វីបានជាវិធី ក ផ្ដល់តម្លៃធំពេក? (ជំនួយ៖ ពហុកោណ «ព្រៃ → កសិកម្ម» មួយ គ្របដណ្ដប់ឃុំប៉ុន្មាន?) · ពេលណាដែល Join attributes by location ជាឧបករណ៍ត្រឹមត្រូវ?

ផែនទីខាងក្រោមបង្ហាញលទ្ធផលរបស់សកម្មភាពទី៤ និងទី៥។ បើកស្រទាប់ **ភាគរយបាត់បង់ព្រៃតាមឃុំ** ពីប៊ូតុងស្រទាប់ ដើម្បីមើលផែនទីពណ៌តាមឃុំ។

## សកម្មភាពទី៦៖ ធ្វើផែនទី និងសរសេរការបកស្រាយ · ២០ នាទី

1. បង្កើតផែនទី A4 ដែលបង្ហាញ `kk_forest_loss` តាមប្រភេទការផ្លាស់ប្ដូរ និងព្រំតំបន់ការពារ។

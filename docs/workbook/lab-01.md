# លំហាត់ទី១៖ ស្គាល់ស្រទាប់ និងសួរសំណួរក្នុង QGIS

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១៖ GIS និងការគិតតាមលំហ](../lessons/lesson-01.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR

## គោលបំណង

- ស្គាល់ស្រទាប់ផ្សេងៗក្នុងតំបន់សិក្សា។
- ភ្ជាប់វត្ថុលើផែនទីទៅនឹងតារាងគុណលក្ខណៈ។
- សង្កេតថាបរិបទអាចផ្លាស់ប្ដូរការបកស្រាយ។
- កំណត់សំណួរមុនការវិភាគ។

## ឯកសារដែលប្រើ

ប្រើឯកសារ `lesson-01-synthetic.gpkg` ក្នុងថត `data`។ ឯកសារនេះមានស្រទាប់ចំនួនប្រាំ៖

| ស្រទាប់ | ខ្លឹមសារ |
|---|---|
| `villages` | ភូមិសន្មត ៣ |
| `schools` | សាលាសន្មត ២ |
| `roads` | កំណាត់ផ្លូវសន្មត ១១ |
| `river` | ទន្លេសន្មត ១ |
| `bridge` | ស្ពានសន្មត ១ |

ទីតាំងទាំងអស់ជាគំរូសន្មតសម្រាប់ការសិក្សា។

## សកម្មភាពទី១៖ បើក និងរៀបចំស្រទាប់ · ១០ នាទី

1. បើក QGIS និងបង្កើតគម្រោងថ្មី។
2. តាមផ្ទាំង **Browser** ស្វែងរកឯកសារ GeoPackage ដែលបានទាញយក។
3. ពង្រីកឯកសារ ហើយបន្ថែមស្រទាប់ទាំងប្រាំ។
4. ពិនិត្យថាគម្រោងប្រើ CRS ដែលសមស្របនឹងទិន្នន័យនេះ៖ **EPSG:32648**។
5. រៀបស្រទាប់ចំណុចនៅខាងលើផ្លូវ និងទន្លេ ដើម្បីងាយមើល។
6. ប្រើនិមិត្តសញ្ញាខុសគ្នាសម្រាប់ភូមិ សាលារៀន និងស្ពាន។

CRS នេះត្រូវបានប្រើសម្រាប់រក្សាទុកគំរូសិក្សា។ ទ្រឹស្ដីនៃការជ្រើសរើស CRS ត្រូវយោងទៅសៀវភៅទី១។

## សកម្មភាពទី២៖ ពិនិត្យទំនាក់ទំនងរវាងផែនទី និងតារាង · ១០ នាទី

1. បើក **Attribute Table** របស់ស្រទាប់ `villages`។
2. ស្វែងរកកំណត់ត្រាដែលមាន `village_id = V1`។
3. ជ្រើសរើសកំណត់ត្រានោះ ហើយមើលវត្ថុដែលត្រូវបានជ្រើសរើសលើផែនទី។
4. កត់ត្រាឈ្មោះ ចំនួនប្រជាជន និងកាលបរិច្ឆេទយោង។

**សំណួរ៖** តើលេខសម្គាល់មានតួនាទីអ្វី? · តើចំនួនប្រជាជនភ្ជាប់ទៅនឹងវត្ថុណា? · តើចំណុច V1 បង្ហាញទីតាំងផ្ទះរបស់ប្រជាជនទាំង ៦០០ នាក់ឬទេ?

## សកម្មភាពទី៣៖ បន្ថែមបរិបទ និងពិនិត្យការបកស្រាយ · ១០ នាទី

1. បង្ហាញតែស្រទាប់ `villages` និង `schools`។
2. សរសេរសាលាដែលមើលទៅនៅជិត V1 ជាងតាមទីតាំង។
3. បើកស្រទាប់ `river`, `roads` និង `bridge`។
4. ពិនិត្យផ្លូវដែលអាចធ្វើដំណើរពី V1 ទៅសាលាទាំងពីរ។

**សំណួរ៖** តើព័ត៌មានណាដែលស្រទាប់ថ្មីបានបន្ថែម? · តើអ្នកត្រូវកែសំណួរ «សាលាណានៅជិត?» ដូចម្ដេច? · តើទិន្នន័យមានព័ត៌មានគ្រប់គ្រាន់សម្រាប់ប្រៀបធៀបពេលវេលាធ្វើដំណើរឬទេ?

## សកម្មភាពទី៤៖ រក្សាទុក និងសរសេរសេចក្ដីសន្និដ្ឋាន · ១០ នាទី

1. រក្សាទុកគម្រោងជា `lesson-01.qgz`។
2. រក្សាឯកសារទិន្នន័យដែលគម្រោងយោងទៅជាមួយគម្រោង។
3. សរសេរសេចក្ដីសន្និដ្ឋាន ៤ ទៅ ៦ ប្រយោគ ដែលមាន៖ សំណួរដែលបានពិនិត្យ · ស្រទាប់ទិន្នន័យដែលបានប្រើ · អ្វីដែលបានសង្កេត · ការសន្មតមួយ · ទិន្នន័យបន្ថែមមួយប្រភេទដែលត្រូវការ។

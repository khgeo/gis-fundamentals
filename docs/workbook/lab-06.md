## ស្ថានភាព

មន្ត្រីអប់រំម្នាក់ផ្ញើតារាងសាលារៀនដែលមានកូអរដោនេ **រយៈទទឹង រយៈបណ្ដោយ** ពីទូរស័ព្ទ។ អ្នកត្រូវនាំតារាងនោះចូល QGIS បម្លែង CRS ឲ្យត្រូវនឹងទិន្នន័យវគ្គសិក្សា ហើយរៀបចំទម្រង់សម្រាប់ប្រមូលទិន្នន័យថ្មីនៅទីវាល។

## គោលបំណង

- នាំចូលតារាង CSV ដែលមានកូអរដោនេ (Delimited Text)។
- បែងចែក CRS ភូមិសាស្ត្រ (EPSG:4326) និង CRS ចំណោល (EPSG:32648) ហើយបម្លែងស្រទាប់។
- រៀបចំ GeoPackage និងទម្រង់បញ្ចូលទិន្នន័យ (Attributes Form)។
- វាយតម្លៃប្រភពទិន្នន័យ៖ អ្នកផលិត ឆ្នាំ ភាពត្រឹមត្រូវ អាជ្ញាបណ្ណ។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។ ស្រទាប់ទាំងអស់ប្រើ **EPSG:32648**។

| ស្រទាប់ | ថត | ខ្លឹមសារ |
|---|---|---|
| `Kh_School` | `School/` | សាលារៀន (ប្រើបង្កើតតារាង CSV គំរូ) |
| `Kh_Province_Boundary` | `Admin/` | ព្រំខេត្ត |

## សកម្មភាពទី១៖ បង្កើតតារាង CSV ដូចពីទូរស័ព្ទ · ១៥ នាទី

ដើម្បីក្លែងធ្វើតារាងពីទីវាល យើងនាំសាលាខេត្តកំពង់ឆ្នាំងចេញជា CSV ដែលមានរយៈទទឹង រយៈបណ្ដោយ។

1. ជ្រើស `Kh_School` ដោយ `"PROVINCE" = 'Kampong Chhnang' AND "SCHOOL_TYP" = 'Lycee G7-12'`
2. ចុចស្ដាំ → **Export → Save Selected Features As**៖

    | ប៉ារ៉ាម៉ែត្រ | តម្លៃ |
    |---|---|
    | Format | Comma Separated Value [CSV] |
    | File name | `kc_lycee.csv` |
    | CRS | **EPSG:4326 - WGS 84** |
    | Layer Options → GEOMETRY | `AS_XY` |

3. បើក `kc_lycee.csv` ក្នុង Notepad។ វាលថ្មី `X` និង `Y` ជា **ដឺក្រេ**។ តើមួយណាជារយៈបណ្ដោយ (longitude)?

## សកម្មភាពទី២៖ នាំចូល CSV និងបម្លែង CRS · ២០ នាទី

1. **Layer → Add Layer → Add Delimited Text Layer**៖ File `kc_lycee.csv` · Point coordinates · X field `X` · Y field `Y` · Geometry CRS **EPSG:4326**។
2. ពិនិត្យថាចំណុចធ្លាក់ត្រូវទីតាំងលើផែនទី។ បើចំណុចធ្លាក់ក្នុងសមុទ្រនៅអាហ្វ្រិក ជាធម្មតាអ្នកប្ដូរ X និង Y ឬកំណត់ CRS ខុស។
3. **Vector → Data Management Tools → Reproject Layer**៖ Target CRS **EPSG:32648** → `kc_lycee_utm.gpkg`
4. បើក Field Calculator លើ `kc_lycee_utm` បង្កើតវាល `E = $x` និង `N = $y`។ ប្រៀបធៀបកូអរដោនេពីរប្រព័ន្ធ។

!!! danger "កុំប្ដូរ CRS ដោយ Set CRS"
    **Set Layer CRS** គ្រាន់តែប្ដូរស្លាក CRS ដោយមិនគណនាកូអរដោនេឡើងវិញ។ ដើម្បីបម្លែងពិតប្រាកដ ត្រូវប្រើ **Reproject Layer** ឬ Export ជាមួយ CRS ថ្មី។ ទ្រឹស្ដី CRS យោងទៅសៀវភៅទី១។

**សំណួរ៖** ហេតុអ្វីមិនអាចវាស់ចម្ងាយជាម៉ែត្រដោយផ្ទាល់លើស្រទាប់ EPSG:4326?

## សកម្មភាពទី៣៖ រៀបចំទម្រង់ប្រមូលទិន្នន័យ · ២៥ នាទី

1. **Layer → Create Layer → New GeoPackage Layer**៖ File `field_survey.gpkg` · Layer `wells` · Geometry **Point** · CRS **EPSG:32648**
2. បន្ថែមវាល៖

    | វាល | ប្រភេទ | គោលបំណង |
    |---|---|---|
    | `well_type` | Text | ប្រភេទអណ្ដូង |
    | `depth_m` | Decimal | ជម្រៅ (ម) |
    | `working` | Boolean | ដំណើរការឬទេ |
    | `survey_date` | Date | ថ្ងៃស្ទង់ |
    | `surveyor` | Text | អ្នកស្ទង់ |

3. **Layer Properties → Attributes Form**៖
    - `well_type` → Widget **Value Map**៖ អណ្ដូងស្នប់ · អណ្ដូងជីក · អណ្ដូងស្នប់អគ្គិសនី
    - `depth_m` → **Range** ពី ០ ដល់ ២០០
    - `survey_date` → Default value `now()`
    - `well_type` → Constraints → **Not null**
4. បើក Toggle editing ហើយបន្ថែមចំណុចសាកល្បង ៣ ដោយចុចលើផែនទី។ សាកល្បងបញ្ចូលជម្រៅ ៥០០ ហើយសង្កេតថាទម្រង់បដិសេធ។

!!! tip "ពីកុំព្យូទ័រទៅទូរស័ព្ទ"
    គម្រោងនេះអាចបើកក្នុងកម្មវិធី **QField** (ឥតគិតថ្លៃ) លើទូរស័ព្ទ Android ដើម្បីប្រមូលទិន្នន័យដោយប្រើ GPS ពិតប្រាកដ។ ទម្រង់ដែលអ្នករៀបចំនៅទីនេះ នឹងបង្ហាញដូចគ្នានៅលើទូរស័ព្ទ។

# មេរៀន ២.១៖ ធាតុផ្សំពីរនៃទិន្នន័យភូមិសាស្ត្រ

!!! warning "ស្ថានភាព៖ គ្រោងមេរៀន"
    ខ្លឹមសារពេញលេញកំពុងសរសេរ។ សូមមើល [មេរៀន ១.១](../ch01/l1.md) សម្រាប់ទម្រង់ពេញលេញ។

## ២.១.០ ពីទិន្នន័យ ទៅព័ត៌មាន ទៅព័ត៌មានលំហ

មុននឹងនិយាយអំពីប្រភេទទិន្នន័យ យើងត្រូវបែងចែកពាក្យបីដែលមនុស្សច្រើនប្រើជំនួសគ្នា ប៉ុន្តែមិនមានន័យដូចគ្នាទេ។

<figure markdown>
--8<-- "assets/svg/fig-04-data-to-spatial.svg"
<figcaption>រូបភាព ២.១៖ កូអរដោនេជាជំហានដែលប្រែព័ត៌មានធម្មតាទៅជាអ្វីដែល GIS គណនាបាន។</figcaption>
</figure>

- **ទិន្នន័យ (Data)** ជាការកត់ត្រាដើម មិនទាន់បកស្រាយ។ ឈ្មោះមួយ លេខមួយ ការវាស់មួយ។
- **ព័ត៌មាន (Information)** កើតឡើងនៅពេលមនុស្សបកស្រាយទិន្នន័យនោះ រួចវាឆ្លើយសំណួរអ្វីមួយ។
- **ព័ត៌មានលំហ (Spatial Information)** គឺព័ត៌មានដែលភ្ជាប់ជាមួយទីតាំងលើផែនដី។

ជំហានទីបីនេះជាចំណុចសំខាន់។ តារាងឈ្មោះមណ្ឌលសុខភាពជាព័ត៌មាន តែវាមិនអាចឆ្លើយសំណួរអំពីចម្ងាយបានទេ។ ពេលបន្ថែមកូអរដោនេចូល ទិន្នន័យដដែលនោះក្លាយជាអ្វីដែល GIS អាចវាស់ ប្រៀបធៀប និងគូសផែនទីបាន។

!!! note "ចំណាំសម្រាប់និស្សិត"
    កុំច្រឡំ «ទិន្នន័យច្រើន» ជាមួយ «ព័ត៌មានច្រើន»។ ឯកសារ Excel ដែលមានជួរដេក ១០០.០០០ ប៉ុន្តែគ្មានកូអរដោនេ នៅតែឥតប្រយោជន៍សម្រាប់សំណួរលំហ។

## ២.១ ធាតុផ្សំពីរនៃទិន្នន័យភូមិសាស្ត្រ

*គ្រោង៖* ទីតាំង + គុណលក្ខណៈ + ពេលវេលា; គំនិត 'តារាងមានផែនទី'

## ២.២ បាតុភូតដាច់ពីគ្នា ទល់នឹង បាតុភូតជាប់គ្នា

*គ្រោង៖* ផ្ទះ/ផ្លូវ/ស្រែ ទល់នឹង កម្ពស់/សីតុណ្ហភាព/ទឹកភ្លៀង; ហេតុអ្វីវាកំណត់ជម្រើសវ៉ិចទ័រ/រ៉ាស្ទ័រ
